Chapter 5 Material Systems and Shaders

Learning Objectives
  • Understand material and shader node systems
  • Master PBR (Physically Based Rendering) material creation
  • Learn texture mapping and UV unwrapping
  • Master procedural material creation
  • Understand lighting models and material interaction

Detailed Knowledge Points

5.1 Material System Basics

5.1.1 Material and Shader Concepts

Material = Collection of properties describing object surface
Shader = Algorithm calculating light-surface interaction

Material Properties Include:

  • Color
  • Reflectance
  • Roughness
  • Metallic
  • Transparency
  • Emission

5.1.2 Blender Material Workflow

# Material creation process
1. Select object
2. Switch to Shading workspace
3. Click "New" to create material
4. Use node editor to edit material
5. View effect in 3D viewport (Material Preview/Rendered)

5.2.2 Core Shader Nodes

Principled BSDF: This is the most important shader node, based on Disney’s PBR standard:

Principled BSDF Parameters:
├── Base Color: Base color
├── Metallic: Metallic (0=insulator, 1=metal)
├── Roughness: Roughness (0=mirror, 1=fully rough)
├── IOR: Index of refraction
├── Alpha: Transparency
├── Subsurface: Subsurface scattering
├── Specular: Specular reflection strength
├── Transmission: Transmission
├── Emission: Emission
└── Normal: Normal map input

Other Important Shaders:

Shader TypePurposeFeatures
Diffuse BSDFDiffuse reflectionIdeal diffuse surface
Glossy BSDFSpecular reflectionMetal and smooth surfaces
Glass BSDFGlassTransparent refractive material
EmissionEmissionSelf-illuminating material
Mix ShaderMix shadersCombine multiple materials

5.3 PBR Material Creation

5.3.1 PBR Workflow

Physically Based Rendering (PBR) Principles:

  • Energy conservation: Reflection + Absorption + Transmission = 1
  • Fresnel effect: Viewing angle affects reflection strength
  • Microfacet theory: Surface roughness affects reflection

PBR Texture Types:

PBR Standard Texture Set:
├── Albedo/Diffuse: Albedo color map
├── Normal: Normal map (surface detail)
├── Roughness: Roughness map
├── Metallic: Metallic map
├── AO: Ambient occlusion map
├── Height/Displacement: Height map
└── Emission: Emission map

5.3.2 Common Material Type Creation

Metal Material:

# Gold material settings
Principled BSDF:
├── Base Color: RGB(1.0, 0.766, 0.336)
├── Metallic: 1.0
├── Roughness: 0.1-0.3
├── IOR: 0.47 (gold's IOR)
└── Specular: 1.0

# Stainless steel material
├── Base Color: RGB(0.672, 0.672, 0.672)
├── Metallic: 1.0
├── Roughness: 0.2-0.5
└── IOR: 2.9

Plastic Material:

# Smooth plastic
Principled BSDF:
├── Base Color: Any color
├── Metallic: 0.0
├── Roughness: 0.1-0.3
├── IOR: 1.45 (typical plastic IOR)
└── Specular: 0.5

Glass Material:

# Transparent glass
Principled BSDF:
├── Base Color: RGB(1.0, 1.0, 1.0)
├── Metallic: 0.0
├── Roughness: 0.0
├── IOR: 1.52 (glass IOR)
├── Transmission: 1.0
└── Alpha: 0.0 (completely transparent)

5.4 Texture Mapping Basics

5.4.1 UV Coordinate System

UV Coordinate Concept:

U axis: Horizontal direction (0-1)
V axis: Vertical direction (0-1)

3D mesh → UV unwrap → 2D texture space

5.4.2 Texture Coordinate Node

Texture Coordinate Node Outputs:

Generated: Auto-generated coordinates
UV: UV map coordinates
Object: Object coordinates
Camera: Camera coordinates
Window: Window coordinates
Normal: Normal coordinates
Reflection: Reflection coordinates

Mapping Node: Used to transform texture coordinates

Mapping Parameters:
├── Location: Position offset
├── Rotation: Rotation angle
├── Scale: Scale ratio
└── Vector Type: Vector type
   ├── Texture: Texture
   ├── Point: Point
   ├── Vector: Vector
   └── Normal: Normal

5.5 Procedural Material Creation

5.5.1 Noise Texture Nodes

Noise Texture:

Parameter settings:
├── Scale: Noise scale
├── Detail: Detail layers
├── Roughness: Roughness
├── Lacunarity: Lacunarity
├── Distortion: Distortion
└── Dimension: Dimension

Outputs:
├── Fac: Grayscale value (0-1)
└── Color: Color noise

Other Procedural Textures:

Texture TypePurposeFeatures
Wave TextureWave textureRegular wave patterns
Voronoi TextureVoronoiCellular patterns
Musgrave TextureFractal noiseComplex terrain texture
Gradient TextureGradient textureLinear/radial gradients
Magic TextureMagic texturePsychedelic patterns
Brick TextureBrick textureBrick wall patterns

5.5.2 ColorRamp Node

ColorRamp is used to remap color values:

# ColorRamp application
Noise texture → ColorRamp → Material parameter

Common techniques:
1. Control contrast (adjust color stop position)
2. Create mask (black and white output)
3. Color layering (multiple color stops)
4. Smooth transition (interpolation type)

5.6 Advanced Shading Techniques

5.6.1 Layered Materials

Using Mix Shader to blend multiple materials:

# Layered material example: Rusted metal
Metal layer (Principled BSDF - metal parameters)
     ↓
Mix Shader
     ↓
Rust layer (Principled BSDF - insulator parameters)

# Mix factor controlled by texture
Noise texture → ColorRamp → Mix Shader.Fac

5.6.2 Subsurface Scattering

Simulates light scattering inside material:

# Skin material
Principled BSDF:
├── Subsurface: 0.1-0.5
├── Subsurface Radius: RGB(1.0, 0.2, 0.1)
├── Subsurface Color: Skin undertone
└── Base Color: Skin surface color

# Candle material
├── Subsurface: 0.3
├── Subsurface Color: Warm yellow
└── Transmission: 0.9

5.6.3 Displacement Mapping

Using height information to change geometry shape:

# Displacement setup process
1. Connect Displacement in material output node
2. Image Texture → ColorRamp → Displacement
3. Add Subdivision Surface in modifiers
4. Enable Adaptive Subdivision (experimental feature)

# Displacement strength control
Math node to adjust displacement strength:
Height Map → Math(Multiply) → Displacement

5.7 Material Optimization and Management

5.7.1 Material Library Management

# Material save and reuse
1. Click "Fake User" button after creating material
2. File → Append/Link to import materials from other files
3. Use Asset Browser to manage material library
4. Create material node groups for easy reuse

# Node group creation
1. Select nodes to group
2. Ctrl + G to create node group
3. Tab to enter node group editing
4. Add input/output nodes to define interface

5.7.2 Render Optimization

# Material render optimization tips
1. Use appropriate texture resolution
   - Background objects: 512x512 or lower
   - Foreground objects: 2048x2048 or higher

2. Avoid overly complex node networks
   - Use node groups to simplify
   - Delete unused nodes

3. Enable GPU render acceleration
   - Cycles: CUDA/OpenCL/OptiX
   - Set appropriate sample count

5.8 Practical Exercises

Exercise 1: Wood Material Creation

Exercise Objective

Master procedural material creation and node combination techniques

# Procedural wood material creation
# Step 1: Create basic wood grain
1. Add Wave Texture node
2. Type: Bands, Profile: Saw
3. Scale: 20, Distortion: 2

# Step 2: Add wood grain variation
4. Add Noise Texture
5. Scale: 5, Detail: 10
6. Connect to Wave Texture Distortion

# Step 3: Color adjustment
7. Wave Texture → ColorRamp
8. Set two color stops: Light wood color and dark wood color
9. ColorRamp → Principled BSDF Base Color

# Step 4: Surface detail
10. Duplicate noise texture for roughness
11. Adjust strength: Math node × 0.3
12. Connect to Roughness input

# Step 5: Normal detail
13. Add another Noise Texture (smaller scale)
14. Connect to Normal Map node
15. Normal Map → Principled BSDF Normal

Exercise 2: Car Paint Material

# Automotive metallic paint material
# Step 1: Base car paint
1. Principled BSDF settings:
   - Base Color: Choose car color
   - Metallic: 0.0 (car paint is insulator)
   - Roughness: 0.1 (smooth)
   - IOR: 1.5

# Step 2: Metallic flake effect
2. Add Noise Texture (Scale: 1000)
3. ColorRamp to adjust contrast
4. Math node to adjust strength × 0.1
5. Connect to Metallic input

# Step 3: Clear coat layer effect
6. Add Mix Shader
7. First input: Car paint material above
8. Second input: Glossy BSDF (Roughness: 0.05)
9. Factor: 0.1 (10% clear coat layer)

# Step 4: Environment reflection enhancement
10. Add Layer Weight node
11. Fresnel output → Mix Shader Factor
12. Enhance edge reflection effect

Exercise 3: Complex Fabric Material

Notes
  • Fabric materials require appropriate UV unwrapping
  • Note anisotropic reflection of fibers
  • Use subsurface scattering to simulate light transmission
# Sweater fabric material
# Step 1: Basic fabric color
1. Choose appropriate fabric albedo color
2. Principled BSDF Base Color

# Step 2: Fabric texture
3. Use Brick Texture to simulate woven texture
4. Scale: 50, Mortar: 0.02
5. Set Color1/Color2 to different shades

# Step 3: Surface fuzz effect
6. Add Hair BSDF
7. Mix Shader to blend Principled and Hair
8. Factor controlled by texture (about 0.3)

# Step 4: Subsurface scattering
9. Enable Subsurface: 0.1
10. Subsurface Color: Slightly warmer than Base Color

# Step 5: Normal detail
11. Use Noise Texture to create subtle bumps
12. Normal Map strength: 0.5
13. Simulate fiber surface texture

5.10 Render Engine Differences

5.10.1 Cycles vs Eevee Material Differences

Cycles (Offline Rendering):

  • Full support for all node types
  • Physically accurate ray tracing
  • Supports complex volume rendering
  • High render quality but slower speed

Eevee (Real-time Rendering):

  • Limited support for some nodes
  • Rasterization-based real-time rendering
  • Requires preprocessing (baking) for certain effects
  • Fast speed but quality compromises

Material Compatibility:

FeatureCyclesEeveeNotes
Principled BSDF✓✓Full support
Volume scatter✓PartialEevee needs volumetrics enabled
Displacement map✓✗Eevee doesn’t support
Subsurface scatter✓✓Both support
IOR refraction✓ApproximateEevee uses screen space
Learning Suggestions
  1. Start with Basics: First master parameters of Principled BSDF
  2. Observe Reality: Observe light and shadow changes in real materials
  3. Experimental Spirit: Try different node combinations
  4. Reference Learning: Study material creation in excellent works
  5. Stay Organized: Use Frame and Reroute nodes to organize complex networks

Through this chapter, you should be able to:

  • Proficiently use shader node systems
  • Create various types of PBR materials
  • Understand procedural material creation methods
  • Master material optimization and management techniques

Material creation is an important component of 3D art, requiring combination of technical knowledge and artistic sense.
