Chapter 4 Advanced Modeling Techniques

Learning Objectives
  • Master subdivision surface modeling
  • Learn to use sculpt mode
  • Understand retopology techniques
  • Master Boolean operations and procedural modeling
  • Learn hard surface and organic modeling methods

Detailed Knowledge Points

4.1 Subdivision Surface Modeling

4.1.1 Subdivision Surface Principles

Subdivision Surface is a technique that uses mathematical algorithms to subdivide low-polygon meshes into smooth surfaces:

Low-poly Mesh → Subdivision Algorithm → High-poly Surface

Catmull-Clark Subdivision Algorithm:

  • Each face is divided into 4 sub-faces
  • New vertex positions based on average of surrounding vertices
  • Increases smoothness while maintaining original shape

4.1.2 Subdivision Surface Modifier

# Add Subdivision Surface modifier
Properties Panel → Modifier Properties → Add Modifier → Subdivision Surface

Important Parameters:
- Levels Viewport: Viewport display level (0-6)
- Render: Render level (0-6)
- Type: Catmull-Clark (smooth) or Simple (non-smooth)
- Use Limit Surface: Use limit surface

Subdivision Level Comparison:

LevelFace IncreaseUse Case
01xOriginal mesh
14xBasic subdivision
216xGeneral purpose
364xFine modeling
4+256x+Special needs

4.1.3 Edge Control Techniques

Edge Loops:

Ctrl + R  # Add edge loop
# Closer edge loops create sharper edges after subdivision

# Creating sharp edges
1. Add tight edge loops where sharpness is needed
2. Adjust edge loop spacing to control sharpness
3. Use Ctrl + B bevel to create transitions

Creasing:

# Set crease
Shift + E  # Crease tool
Input value: 0 (no crease) to 1 (full crease)

# Application scenarios
- Maintain hard edges without adding geometry
- Partially sharpen edges
- Control subdivision behavior

4.2 Sculpt Mode

4.2.1 Sculpting Basics

Sculpt mode allows shaping models like working with digital clay:

# Enter Sculpt mode
1. Select object
2. Switch to Sculpting workspace
3. Or select Sculpting Mode from mode menu

Sculpt Brush Types:

SculptBasic sculptingX
SmoothSmoothS

4.2.2 Dynamic Topology (Dyntopo)

# Enable dynamic topology
Ctrl + D  # Toggle dynamic topology

Dynamic topology settings:
- Detail Size: Detail size (pixels)
- Relative Detail: Relative detail
- Detailing: Detail type
  - Subdivide Edges: Subdivide edges
  - Collapse Edges: Collapse edges
  - Subdivide Collapse: Combined mode

Dynamic Topology Workflow:

# 1. Start with simple mesh
Add UV Sphere or Cube

# 2. Enable dynamic topology
Ctrl + D

# 3. Use sculpt brushes to shape
- Push and pull basic shapes
- Add large form changes
- Gradually refine details

# 4. Adjust detail density
- High detail areas: Lower Detail Size
- Low detail areas: Increase Detail Size

4.2.3 Multiresolution Sculpting

# Multiresolution modifier workflow
1. Add Multiresolution modifier
2. Subdivide to create subdivision levels
3. Sculpt at different levels
4. Higher Levels: Detail sculpting
5. Lower Levels: Overall shape adjustment

Multiresolution advantages:
- Maintain low poly for animation
- High poly for detail sculpting
- Can bake normal maps

4.3 Retopology Techniques

4.3.1 Importance of Retopology

Why retopology is needed:

  • Sculpted meshes have chaotic topology
  • Animation requires clean quad mesh
  • Reduce polygon count to optimize performance
  • Create clear edge flow structure

4.3.2 Manual Retopology

# Manual retopology tools
1. Enable Snap to face
2. Create new plane or use existing mesh
3. Recreate topology over original model

Retopology tools:
- PolyBuild: Interactive polygon building
- Knife: Knife tool
- F: Fill face
- J: Connect vertices

Retopology Best Practices:

# Edge flow direction guidance
Muscle flow → Edge flow follows muscle texture
Joint areas → Circular edge flow for deformation
Eye area → Radial edge flow
Mouth area → Circular edge flow around lips

# Polygon count control
Game character: 5,000-20,000 faces
Film character: 50,000-200,000 faces
Real-time application: As low polygon as possible

4.3.3 Automatic Retopology

# Quad Remesh
Mesh → Remesh → Quad Remesh

Parameters:
- Octree Depth: Detail level
- Scale: Scale factor
- Sharpness: Sharpness
- Dual Mesh: Dual mesh

4.4 Boolean Operations

4.4.1 Boolean Operation Types

# Three Boolean operation types
Union: A ∪ B - Merge two objects
Difference: A - B - Subtract B from A
Intersect: A ∩ B - Keep overlapping part

4.4.2 Boolean Modifier

# Add Boolean modifier
Properties → Modifier Properties → Boolean

Parameter settings:
- Operation: Operation type
- Object: Target object
- Solver: Solver
  - Fast: Fast (may have accuracy issues)
  - Exact: Exact (slower but accurate)

Boolean Operation Example:

# Creating screw head slot
1. Create cylinder as screw
2. Create cube as slot
3. Rotate cube 45 degrees and adjust size
4. Add Boolean modifier to screw
5. Operation: Difference
6. Object: Cube
7. Apply modifier

4.4.3 Boolean Operation Best Practices

Boolean Operation Notes
  • Ensure mesh is closed (Manifold)
  • Avoid overlapping edges and faces
  • Use Exact solver for better results
  • Check and repair mesh after Boolean operation
# Preparation before Boolean operations
1. Check mesh integrity
   - Mesh → Clean up → Fill Holes
   - Mesh → Normals → Recalculate Outside

2. Ensure appropriate mesh density
   - Too dense: Slow operation
   - Too sparse: Detail loss

3. Use modifiers instead of direct application
   - Maintain non-destructive workflow
   - Can adjust parameters anytime

4.5 Hard Surface Modeling

4.5.1 Hard Surface Modeling Principles

Hard surface modeling is used for creating mechanical, architectural, product items with clear boundaries:

# Hard surface modeling characteristics
- Clear edges and corners
- Flat surfaces
- Regular geometric shapes
- Precise dimensional control

4.5.2 Hard Surface Modeling Techniques

Modifier Stack Combination:

# Typical hard surface modifier stack
1. Mirror - Symmetrical modeling
2. Array - Repeated elements
3. Solidify - Add thickness
4. Bevel - Round edges
5. Subdivision Surface - Final smoothing

# Modifier order is important!

Modeling Techniques:

# 1. Start from silhouette
Add basic shape → Extrude silhouette → Add details

# 2. Use precise measurements
Tab to input exact values
Enable snapping and increments

# 3. Keep clean topology
Primarily use quads
Avoid n-gons and triangles

4.5.3 Mechanical Part Modeling Example

# Creating a gear
1. Add circle (24 vertices)
2. Enter Edit Mode, select all
3. Alt + E → Extrude Individual Faces
4. S → 0.8 (scale inward)
5. E → extrude outward for teeth
6. Ctrl + R add edge loops for center hole
7. I → inset to create inner ring
8. Delete Faces → delete center
9. Add subdivision and bevel modifiers

4.6 Organic Modeling

4.6.1 Box Modeling Method

Start from simple cube to create complex organic forms:

# Box modeling steps
1. Start with cube
2. Use loop cuts to divide main structure
3. Extrude to create limbs and appendages
4. Gradually refine shape
5. Use proportional editing to smooth transitions
6. Add Subdivision Surface modifier

4.6.2 Organic Modeling Techniques

Form Control:

# Proportional Editing
O  # Enable proportional editing
Scroll wheel # Adjust influence range
Alt + O # Toggle connected mode

# Smooth tools
Alt + S # Scale along normals (inflate/deflate)
Shift + Alt + S # Smooth scale along normals

Muscle Flow Modeling:

# Follow anatomical structure
1. Study real anatomical references
2. Edge flow follows muscle texture
3. Focus on joints and deformation areas
4. Maintain symmetry (use Mirror modifier)

4.7 Practical Exercises

Exercise 1: Coffee Cup Modeling (Subdivision Surface)

Exercise Objective

Master basic subdivision surface modeling workflow and edge control

# Creating coffee cup using subdivision surface
# Step 1: Create cup body outline
1. Delete default cube
2. Shift + A → Mesh → Cylinder (Vertices: 12)
3. Tab to enter Edit Mode
4. Select top face, Delete → Faces (create opening)

# Step 2: Shape cup body
5. 2 → Switch to edge select mode
6. Alt + left-click to select edge loops at different heights
7. S → Scale different loops to create cup profile
8. Select opening edge loop, E → extrude inward to create cup rim thickness

# Step 3: Add subdivision
9. Add Subdivision Surface modifier (Level: 2)
10. Add edge loops where sharpness is needed (Ctrl + R)
11. Adjust loop positions to control curvature

# Step 4: Create handle
12. Select two faces on cup side
13. E → Extrude, S → 0 to merge
14. E → Continue extruding to form handle shape
15. Use G and R to adjust handle arc

Exercise 2: Simple Character Head (Sculpting)

# Creating character head using sculpt mode
# Step 1: Prepare base model
1. Add UV Sphere
2. Switch to Sculpting workspace
3. Ctrl + D to enable dynamic topology

# Step 2: Shape basic head form
4. Use Grab brush (G) to adjust head proportions
5. Use Snake Hook (K) to pull out nose
6. Inflate (I) to thicken lip area
7. Use Grab brush to adjust eye socket depth

# Step 3: Add details
8. Lower Detail Size to increase detail density
9. Use Clay Strips to add muscle texture
10. Smooth brush (S) to smooth transition areas
11. Use standard sculpt brush to add wrinkles and other details

# Step 4: Refine and optimize
12. Use Quad Remesh to retopologize
13. Manually adjust key edge flows
14. Add Subdivision Surface modifier

Exercise 3: Mechanical Part (Hard Surface + Boolean)

Notes
  • Hard surface modeling requires precise measurements and symmetry
  • Boolean operations require mesh integrity
  • Use proper modifier stack order
# Creating bolt and nut combination
# Bolt creation:
1. Add cylinder (12 vertices)
2. S → X/Y → 0.5 to reduce diameter
3. S → Z → 3 to elongate
4. Select top face, E → extrude bolt head
5. S → 1.5 to enlarge bolt head

# Thread creation:
6. Add another cylinder for threads
7. Add Screw modifier
8. Adjust parameters to create thread effect
9. Use Boolean modifier to merge with bolt

# Nut creation:
10. Add cylinder
11. In Edit Mode select 6 faces to create hexagon
12. I → inset to create inner hole
13. Delete Faces to remove center
14. Use Boolean modifier to cut thread hole

# Assembly and rendering:
15. Insert bolt into nut
16. Add metal materials
17. Set appropriate lighting
18. Render final result

4.9 Modeling Workflow Optimization

4.9.1 Non-Destructive Modeling

# Modeling workflow recommendations
1. Use modifiers instead of direct operations
2. Keep original mesh simple
3. Apply modifiers in stages
4. Backup important milestones

# Modifier stack management
- Mirror at bottom (affects all subsequent modifiers)
- Subdivision at top (apply smoothing last)
- Boolean in middle at appropriate position
- Can adjust order and parameters anytime

4.9.2 Performance Optimization

# Improve modeling performance
1. Set subdivision levels appropriately
   - Use low level when editing
   - Use high level when rendering

2. Use simplified display
   - Wireframe mode editing
   - Hide unnecessary objects
   - Use hierarchical management

3. Clean scene regularly
   - Delete unused meshes
   - Merge similar objects
   - Apply modifiers no longer needed
Learning Suggestions
  1. Progressive Learning: Start with simple shapes, gradually increase complexity
  2. Practice-Oriented: Do more practice projects, combine theory with practice
  3. Reference Learning: Observe forms and structures of real objects
  4. Tool Proficiency: Master shortcuts for various modeling tools
  5. Be Patient: Complex modeling requires time and experience accumulation

Through this chapter, you should be able to:

  • Proficiently use subdivision surface for organic modeling
  • Master sculpting tools to create complex details
  • Understand and apply retopology techniques
  • Use Boolean operations for complex modeling
  • Possess hard surface and organic modeling capabilities

These advanced modeling techniques are key skills for creating professional-grade 3D models and require extensive practice to master.
