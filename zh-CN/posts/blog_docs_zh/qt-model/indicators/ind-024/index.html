威廉鳄鱼指标 (Williams Alligator)

Haiyue
2026年4月1日
9分钟

威廉鳄鱼指标 (Williams Alligator)

指标概览
  • 类别：趋势类 (Trend) — 叠加指标
  • 默认参数：jawPeriod=13, teethPeriod=8, lipsPeriod=5; jawShift=8, teethShift=5, lipsShift=3
  • 输出：三条平滑移动平均线（Jaw, Teeth, Lips）
  • 适用市场：股票、期货、外汇、加密货币

一、什么是威廉鳄鱼指标

威廉鳄鱼指标（Williams Alligator）由美国著名交易员和技术分析师 Bill Williams（比尔·威廉姆斯）创建，首次发表在其 1995 年出版的经典著作《Trading Chaos》中。

Bill Williams 将市场比喻为一只鳄鱼（Alligator），用三条具有不同周期和位移的平滑移动平均线（SMMA）来模拟鳄鱼的”下颌”（Jaw）、“牙齿”（Teeth）和”嘴唇”（Lips）。这三条线的相对位置和交缠状态反映了市场的不同阶段。

三条线的定义

线名颜色计算含义
Jaw（下颌）蓝色SMMA(median, 13)，前移 8 期长期趋势，鳄鱼的”下颌骨”
Teeth（牙齿）红色SMMA(median, 8)，前移 5 期中期趋势，鳄鱼的”牙齿”
Lips（嘴唇）绿色SMMA(median, 5)，前移 3 期短期趋势，鳄鱼的”嘴唇”

其中 median=(High+Low)/2median = (High + Low) / 2median=(High+Low)/2（中位价格）。

鳄鱼的四种状态

Bill Williams 用鳄鱼的行为来描述市场状态：

  1. Sleeping（沉睡）：三条线交缠在一起，鳄鱼闭着嘴 → 市场处于盘整/无趋势状态
  2. Awakening（苏醒）：三条线开始分离，鳄鱼张开嘴 → 新趋势即将启动
  3. Eating（进食）：三条线明显分开，按正确顺序排列 → 市场处于强趋势中
  4. Sated（饱足）：三条线开始收敛，鳄鱼合上嘴 → 趋势即将结束
Bill Williams 的交易哲学

Bill Williams 的核心理念是”混沌理论应用于交易”。他认为市场天然是混沌的，交易者不应试图预测市场，而应识别并跟随市场的自然状态。鳄鱼指标正是这一哲学的体现——它不预测方向，只告诉你市场当前处于什么”阶段”。

二、数学原理与计算方法

前置知识：SMMA（平滑移动平均）

SMMA（Smoothed Moving Average）也叫 RMA（Running Moving Average）或 Wilder 平滑，其递推公式为：

SMMAt=SMMAt−1×(n−1)+PricetnSMMA_t = \frac{SMMA_{t-1} \times (n - 1) + Price_t}{n}SMMAt​=nSMMAt−1​×(n−1)+Pricet​​

初始值为前 nnn 期的简单平均：

SMMAn=1n∑i=1nPriceiSMMA_n = \frac{1}{n}\sum_{i=1}^{n} Price_iSMMAn​=n1​∑i=1n​Pricei​

SMMA 相当于一个衰减系数为 α=1/n\alpha = 1/nα=1/n 的指数平滑，比标准 EMA（α=2/(n+1)\alpha = 2/(n+1)α=2/(n+1)）更平滑、滞后更大。

中位价格

Mediant=Hight+Lowt2Median_t = \frac{High_t + Low_t}{2}Mediant​=2Hight​+Lowt​​

三条线的计算

Jaw（蓝线）：

Jawt=SMMA(Median,13)t−8Jaw_t = SMMA(Median, 13)_{t-8}Jawt​=SMMA(Median,13)t−8​

即先对 Median 计算 13 期 SMMA，然后将结果向右平移 8 期。

Teeth（红线）：

Teetht=SMMA(Median,8)t−5Teeth_t = SMMA(Median, 8)_{t-5}Teetht​=SMMA(Median,8)t−5​

8 期 SMMA，向右平移 5 期。

Lips（绿线）：

Lipst=SMMA(Median,5)t−3Lips_t = SMMA(Median, 5)_{t-3}Lipst​=SMMA(Median,5)t−3​

5 期 SMMA，向右平移 3 期。

位移（Shift）的作用

向前位移使曲线在时间轴上右移，增加了额外的滞后。这是 Bill Williams 有意为之的设计：

  • 不同的位移量使三条线在趋势转折点附近产生交叉时差
  • 位移越大的线（Jaw）变化越慢，代表更长期的趋势
  • 位移最小的线（Lips）反应最快，最先对价格变化做出响应

趋势状态判断

上升趋势（看涨进食）：

Lips>Teeth>Jaw（绿线在最上方，蓝线在最下方）Lips > Teeth > Jaw \quad \text{（绿线在最上方，蓝线在最下方）}Lips>Teeth>Jaw（绿线在最上方，蓝线在最下方）

下降趋势（看跌进食）：

Lips<Teeth<Jaw（绿线在最下方，蓝线在最上方）Lips < Teeth < Jaw \quad \text{（绿线在最下方，蓝线在最上方）}Lips<Teeth<Jaw（绿线在最下方，蓝线在最上方）

盘整（沉睡）：三条线交缠，无明确排列顺序。

三、Python 代码实现

import numpy as np
import pandas as pd

def smma(series: np.ndarray, period: int) -> np.ndarray:
    """
    计算平滑移动平均（SMMA / RMA / Wilder Smooth）。

    参数
    ----------
    series : 价格序列（numpy array）
    period : 平滑周期

    返回
    ----------
    numpy array，长度与输入相同，前 period-1 个值为 NaN
    """
    n = len(series)
    result = np.full(n, np.nan)

    # 初始值：前 period 个数据的简单平均
    result[period - 1] = np.mean(series[:period])

    # 递推
    for i in range(period, n):
        result[i] = (result[i - 1] * (period - 1) + series[i]) / period

    return result


def williams_alligator(df: pd.DataFrame,
                       jaw_period: int = 13,
                       teeth_period: int = 8,
                       lips_period: int = 5,
                       jaw_shift: int = 8,
                       teeth_shift: int = 5,
                       lips_shift: int = 3) -> pd.DataFrame:
    """
    计算 Williams Alligator 指标。

    参数
    ----------
    df : DataFrame，需包含 'high', 'low' 列
    jaw_period : 下颌周期，默认 13
    teeth_period : 牙齿周期，默认 8
    lips_period : 嘴唇周期，默认 5
    jaw_shift : 下颌前移期数，默认 8
    teeth_shift : 牙齿前移期数，默认 5
    lips_shift : 嘴唇前移期数，默认 3

    返回
    ----------
    DataFrame，包含 'jaw', 'teeth', 'lips', 'state' 列
    """
    # 中位价格
    median = ((df['high'] + df['low']) / 2).values

    # 计算 SMMA
    jaw_raw = smma(median, jaw_period)
    teeth_raw = smma(median, teeth_period)
    lips_raw = smma(median, lips_period)

    # 应用位移（向右平移 = 在 pandas 中 shift 正值）
    jaw_series = pd.Series(jaw_raw, index=df.index).shift(jaw_shift)
    teeth_series = pd.Series(teeth_raw, index=df.index).shift(teeth_shift)
    lips_series = pd.Series(lips_raw, index=df.index).shift(lips_shift)

    result = pd.DataFrame({
        'jaw': jaw_series,
        'teeth': teeth_series,
        'lips': lips_series
    }, index=df.index)

    # 判断鳄鱼状态
    def classify_state(row):
        if pd.isna(row['jaw']) or pd.isna(row['teeth']) or pd.isna(row['lips']):
            return 'unknown'
        j, t, l = row['jaw'], row['teeth'], row['lips']
        if l > t > j:
            return 'eating_bull'    # 看涨进食
        elif l < t < j:
            return 'eating_bear'    # 看跌进食
        else:
            # 检查线间距离判断是沉睡还是苏醒/饱足
            spread = max(j, t, l) - min(j, t, l)
            avg = (j + t + l) / 3
            if avg > 0 and spread / avg < 0.005:
                return 'sleeping'   # 沉睡（线间距小于 0.5%）
            else:
                return 'transitioning'  # 过渡（苏醒/饱足）

    result['state'] = result.apply(classify_state, axis=1)

    return result

关于 SMMA 的实现差异

不同平台对 SMMA 的实现可能略有差异（主要在初始值的处理上）。MetaTrader 使用前 N 个数据的 SMA 作为初始值，TradingView 则可能使用 EMA 的等效公式。这会导致指标在初始阶段的数值稍有不同，但长期来看趋于一致。

四、指标能解决的问题

1. 市场阶段识别

鳄鱼指标最核心的价值是帮助交易者识别市场当前处于哪个阶段：

鳄鱼状态市场含义交易建议
Sleeping（沉睡）无趋势，盘整不交易或使用震荡策略
Awakening（苏醒）趋势即将启动准备入场，等待确认
Eating（进食）强趋势进行中顺势加仓或持仓不动
Sated（饱足）趋势即将结束逐步止盈或收紧止损

2. 趋势方向确认

  • 看涨排列（Lips > Teeth > Jaw）→ 做多
  • 看跌排列（Lips < Teeth < Jaw）→ 做空

3. 入场时机

Bill Williams 建议在鳄鱼”苏醒”时入场，具体条件：

  • 三条线从交缠开始分离
  • 价格突破 Lips（嘴唇线）
  • 方向与分离方向一致

4. 出场时机

  • 三条线开始收敛（鳄鱼”饱足”）
  • Lips 回穿 Teeth
  • 价格回落到 Teeth（牙齿线）以下（多头）或以上（空头）

5. 过滤交易信号

鳄鱼沉睡时，其他指标产生的信号可信度降低。将鳄鱼状态作为前置过滤器：只在鳄鱼进食期间执行其他系统的信号。

Bill Williams 的交易规则

Bill Williams 在其交易系统中并不单独使用鳄鱼指标，而是将其与分形（Fractals）和动量振荡器（Awesome Oscillator / Accelerator Oscillator）组合使用，形成完整的”混沌交易法”。

五、优缺点与适用场景

优点

  1. 市场阶段划分清晰：四种状态与真实市场行为高度对应
  2. 直觉性强：鳄鱼的隐喻使概念易于理解和记忆
  3. 过滤横盘噪声：在盘整期间明确告知”不要交易”
  4. 多时间框架一致：在日线、4H、1H 等不同周期上表现一致
  5. 与 Williams 系统互补：与分形和 AO/AC 指标搭配使用效果显著

缺点

  1. 滞后性明显：SMMA 本身已有滞后，加上前移（shift），三条线对价格变化的反应较慢
  2. 趋势初期信号延迟：新趋势可能已走了一段后鳄鱼才”苏醒”
  3. 状态判断有主观性：交缠/分离的判断标准难以精确量化
  4. 震荡市中三线反复交缠：无法给出有效信号
  5. 参数固定：Bill Williams 坚持使用固定参数，但不同市场/周期可能需要调整

最佳实践
  • 严格遵守”沉睡不交易”原则：鳄鱼交缠时市场无趋势，强行交易只会亏损
  • 结合分形突破入场：在鳄鱼苏醒方向上，等待上分形（做多）或下分形（做空）被突破后入场
  • 使用 Teeth（牙齿线）作为跟踪止损位：收盘价跌破牙齿线平仓
  • 多时间框架配合：大周期鳄鱼进食确认趋势方向，小周期鳄鱼苏醒寻找入场点
  • 鳄鱼”进食”时间越长，“饱足”后的回调通常越大——注意及时止盈
