平均价格 (Average Price)

Haiyue
2026年4月1日
6分钟

一、什么是 Average Price 指标

平均价格（Average Price）是一种将单根 K 线的四个价格要素——开盘价（Open）、最高价（High）、最低价（Low）、收盘价（Close）取算术平均值的简单价格计算方法。它提供了每根 K 线交易活动的综合价格代表值。

历史背景

Average Price 并不是由某一位分析师「发明」的指标，而是一种源自统计学基本思想的价格表示方法。在技术分析的早期发展中，分析师需要一种比单纯使用收盘价更全面的方式来描述每根 K 线的价格水平。将 OHLC 四个价格取平均就是最自然的选择。这种做法在日本蜡烛图分析和西方棒线图分析中都有悠久的历史。

与 Typical Price（三价平均）和 Median Price（两价平均）不同，Average Price 纳入了所有四个价格组成部分，提供了最全面的单根 K 线价格摘要。

指标分类

  • 类型：叠加指标（Overlay），直接绘制在价格图表上
  • 大类：其他叠加指标（Other Overlay）/ 价格变换
  • 默认参数：无参数，逐根 K 线独立计算
  • 数据要求：需要 OHLC 数据
与收盘价的区别

大多数指标默认使用收盘价作为输入。但收盘价仅反映最后成交的价格，而 Average Price 兼顾了开盘博弈、盘中波动（高低点）和最终结算（收盘），提供了更均衡的价格视角。

二、数学原理与计算方法

核心公式

Average Price 的计算极为简单——对 OHLC 四个价格取算术平均：

APt=Ot+Ht+Lt+Ct4AP_t = \frac{O_t + H_t + L_t + C_t}{4}APt​=4Ot​+Ht​+Lt​+Ct​​

其中：

  • OtO_tOt​ 为第 ttt 根 K 线的开盘价
  • HtH_tHt​ 为第 ttt 根 K 线的最高价
  • LtL_tLt​ 为第 ttt 根 K 线的最低价
  • CtC_tCt​ 为第 ttt 根 K 线的收盘价

逐步计算逻辑

  1. 获取单根 K 线数据：读取该 K 线的 Open、High、Low、Close 四个价格。
  2. 求和：将四个价格相加。
  3. 除以 4：得到平均价格。
  4. 逐根计算：每根 K 线独立计算，不需要前序数据。

数学性质

Average Price 具有以下数学性质：

  • 有界性：Lt≤APt≤HtL_t \leq AP_t \leq H_tLt​≤APt​≤Ht​，平均价格始终在最高价和最低价之间
  • 等权性：四个价格的权重均为 14=25%\frac{1}{4} = 25\%41​=25%
  • 无记忆性：每根 K 线的 AP 独立计算，不依赖历史数据

与其他价格类型的关系

几种常用的价格计算方式可以用统一的框架来理解：

价格类型公式包含的价格
Average Price(O+H+L+C)/4(O+H+L+C)/4(O+H+L+C)/4O、H、L、C
Typical Price(H+L+C)/3(H+L+C)/3(H+L+C)/3H、L、C
Median Price(H+L)/2(H+L)/2(H+L)/2H、L
Weighted Close(H+L+2C)/4(H+L+2C)/4(H+L+2C)/4H、L、C（C 双倍权重）
为什么不同指标选择不同的价格类型？

不同的价格类型对应不同的「信息侧重」。Average Price 最为均衡；Typical Price 更关注收盘定价；Median Price 仅关注波动范围的中心。选择哪种取决于分析目的。

三、Python 代码实现

import numpy as np
import pandas as pd

def average_price(open_: pd.Series, high: pd.Series,
                  low: pd.Series, close: pd.Series) -> pd.Series:
    """
    计算平均价格 (Average Price)

    Parameters
    ----------
    open_ : pd.Series
        开盘价序列
    high : pd.Series
        最高价序列
    low : pd.Series
        最低价序列
    close : pd.Series
        收盘价序列

    Returns
    -------
    pd.Series
        平均价格序列
    """
    result = (open_ + high + low + close) / 4.0
    result.name = "AvgPrice"
    return result


def average_price_numpy(open_: np.ndarray, high: np.ndarray,
                        low: np.ndarray, close: np.ndarray) -> np.ndarray:
    """
    使用 numpy 计算平均价格（用于理解原理）
    """
    return (open_ + high + low + close) / 4.0


# ========== 使用示例 ==========
if __name__ == "__main__":
    np.random.seed(42)
    dates = pd.date_range("2024-01-01", periods=100, freq="D")
    price = 100 + np.cumsum(np.random.randn(100) * 0.5)

    df = pd.DataFrame({
        "date": dates,
        "open":  price + np.random.randn(100) * 0.3,
        "high":  price + np.abs(np.random.randn(100) * 0.6),
        "low":   price - np.abs(np.random.randn(100) * 0.6),
        "close": price + np.random.randn(100) * 0.1,
        "volume": np.random.randint(1000, 10000, size=100),
    })
    df.set_index("date", inplace=True)

    # 计算 Average Price
    df["avg_price"] = average_price(df["open"], df["high"],
                                    df["low"], df["close"])

    # 同时计算其他价格类型用于对比
    df["typical_price"] = (df["high"] + df["low"] + df["close"]) / 3
    df["median_price"] = (df["high"] + df["low"]) / 2

    # 打印对比结果
    print("=== 各价格类型对比（最后 10 天） ===")
    print(df[["close", "avg_price", "typical_price", "median_price"]].tail(10))

    # Average Price 与 Close 的偏差分析
    df["ap_close_diff"] = df["avg_price"] - df["close"]
    print(f"\nAverage Price 与 Close 的平均偏差: {df['ap_close_diff'].mean():.4f}")
    print(f"偏差标准差: {df['ap_close_diff'].std():.4f}")

    # 使用 Average Price 作为均线输入源
    df["AP_SMA_20"] = df["avg_price"].rolling(window=20).mean()
    df["Close_SMA_20"] = df["close"].rolling(window=20).mean()

    print("\n=== 基于不同价格源的 SMA(20) 对比 ===")
    print(df[["AP_SMA_20", "Close_SMA_20"]].tail(10))

四、指标能解决的问题

1. 提供更全面的价格代表值

单纯使用收盘价会忽略盘中的交易信息。Average Price 综合了四个维度：

  • 开盘价：反映隔夜情绪和开盘博弈
  • 最高价：反映多方力量的极限
  • 最低价：反映空方力量的极限
  • 收盘价：反映当期的最终共识

2. 作为其他指标的输入源

许多技术指标允许选择不同的价格源。使用 Average Price 作为输入可以让这些指标更平稳：

  • SMA、EMA 等移动平均线
  • RSI、CCI 等振荡指标
  • 布林带等通道指标

3. 平滑极端 K 线的影响

在出现长影线（上影线或下影线很长）的 K 线中，收盘价可能偏离中心位置较远。Average Price 通过纳入高低点，能更好地反映该 K 线交易的「重心」位置。

4. 回测中的成交价估算

在量化策略回测中，如果模型假设在 K 线内成交，Average Price 可以作为一种合理的成交价估算——它比仅使用 Open 或 Close 更接近真实的平均成交成本。

注意

Average Price 是逐根 K 线独立计算的，本身不产生趋势或交叉信号。它需要与其他分析方法结合使用才能生成交易决策。

优点

优点说明
计算极简仅需一次加法和一次除法，无任何参数
信息全面纳入所有四个 OHLC 价格，比收盘价更完整
无滞后逐根 K 线计算，没有窗口带来的滞后问题
通用性强可用于任何时间框架、任何市场

缺点

缺点说明
信号单一本身不生成买卖信号，必须作为其他工具的辅助
等权假设对四个价格赋予相同权重，但实际上收盘价可能更重要
忽略成交量不考虑成交量信息，无法反映真实的交易成本
与收盘价差异小在趋势明确时与收盘价差异不大，额外信息有限

适用场景

  • 作为指标输入源：替代收盘价作为 SMA、EMA、RSI 等指标的计算输入
  • 回测成交价估算：在策略回测中作为更合理的假设成交价
  • 数据平滑预处理：在量化建模中作为原始价格的平滑版本
  • 多时间框架分析：在较大时间框架上比收盘价能更好地代表一段时间的交易活动

实战建议
  1. 如果你的策略对长影线较敏感（比如使用收盘价触发止损），可以考虑用 Average Price 替代收盘价，以减少被影线「假突破」欺骗的概率。
  2. 在比较不同资产的日内波动时，Average Price 比收盘价能提供更稳定的基准。
  3. 对于 Heikin-Ashi 蜡烛图分析者，Average Price 实际上就是 Heikin-Ashi Close 的定义公式。
