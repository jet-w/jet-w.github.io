最小二乘移动平均线 (LSMA)

Haiyue
2026年4月1日
7分钟

一、什么是 LSMA 指标

最小二乘移动平均线（Least Squares Moving Average，简称 LSMA）是一种基于线性回归的移动平均线，也被称为线性回归值（Linear Regression Value）或端点移动平均线（End Point Moving Average）。它在滑动窗口内对价格数据拟合一条最佳直线（最小二乘法），然后取该直线在窗口最右端（最新时间点）的值作为指标输出。

历史背景

LSMA 的数学基础——最小二乘法由 Carl Friedrich Gauss（高斯）和 Adrien-Marie Legendre（勒让德）在 19 世纪初独立发现。将线性回归应用于金融时间序列的思路在 20 世纪后半叶逐渐成熟。LSMA 作为技术指标的使用在计算机普及后变得实用，因为每个时间点都需要完成一次线性回归拟合，计算量远大于简单的加权平均。

指标分类

  • 类型：叠加指标（Overlay），绑定在价格图表上
  • 大类：移动平均线类（Moving Averages）
  • 默认参数：周期 n=20n = 20n=20，数据源为收盘价（Close）
LSMA 的本质

LSMA 不是传统意义上的「平均」，而是线性回归的端点预测值。它假设窗口内价格呈线性趋势，并给出该趋势在当前时刻的最佳估计。这使得 LSMA 在趋势市场中具有天然的前瞻性。

二、数学原理与计算方法

线性回归基础

在窗口 [t−n+1,t][t-n+1, t][t−n+1,t] 内，LSMA 对价格序列拟合线性模型：

P^i=a+b⋅xi\hat{P}_i = a + b \cdot x_iP^i​=a+b⋅xi​

其中 xi=i−xˉx_i = i - \bar{x}xi​=i−xˉ（居中化的时间索引），i=0,1,…,n−1i = 0, 1, \ldots, n-1i=0,1,…,n−1。

使用最小二乘法，斜率 bbb 和截距 aaa 的解为：

b=∑i=0n−1(xi−xˉ)(Pi−Pˉ)∑i=0n−1(xi−xˉ)2b = \frac{\sum_{i=0}^{n-1} (x_i - \bar{x})(P_i - \bar{P})}{\sum_{i=0}^{n-1} (x_i - \bar{x})^2}b=∑i=0n−1​(xi​−xˉ)2∑i=0n−1​(xi​−xˉ)(Pi​−Pˉ)​

a=Pˉ−b⋅xˉa = \bar{P} - b \cdot \bar{x}a=Pˉ−b⋅xˉ

其中 xˉ=n−12\bar{x} = \frac{n-1}{2}xˉ=2n−1​，Pˉ=1n∑Pi\bar{P} = \frac{1}{n}\sum P_iPˉ=n1​∑Pi​。

LSMA 的值

LSMA 取线性回归在窗口最右端点（x=n−1x = n - 1x=n−1）处的拟合值：

LSMAt=a+b⋅(n−1)LSMA_t = a + b \cdot (n - 1)LSMAt​=a+b⋅(n−1)

简化公式

经过推导，LSMA 可以表示为价格的加权平均，其权重公式为：

wi=6(2i−n+1)n(n2−1)+1nw_i = \frac{6(2i - n + 1)}{n(n^2 - 1)} + \frac{1}{n}wi​=n(n2−1)6(2i−n+1)​+n1​

其中 i=0,1,…,n−1i = 0, 1, \ldots, n-1i=0,1,…,n−1（0 为最旧数据）。这组权重之和为 1，且对最新数据赋予最大权重，对最旧数据赋予最小（甚至为负的）权重。

负权重

LSMA 的权重可能为负值！对于窗口中最旧的数据点，权重为负意味着旧数据对 LSMA 值有反向贡献。这是 LSMA 区别于所有其他移动平均线的独特特征，也是它能够「前瞻」的数学原因。

与其他回归指标的关系

指标含义
LSMA（端点值）回归线在 x=n−1x = n-1x=n−1 处的值
Linear Regression Slope斜率 bbb，反映趋势强度
Linear Regression Intercept截距 aaa
R-Squared拟合优度，反映线性趋势的可靠性

三、Python 代码实现

import numpy as np
import pandas as pd

def lsma(close: pd.Series, period: int = 20) -> pd.Series:
    """
    计算最小二乘移动平均线 (LSMA)

    Parameters
    ----------
    close : pd.Series
        收盘价序列
    period : int
        计算周期，默认为 20

    Returns
    -------
    pd.Series
        LSMA 值序列（线性回归端点值）
    """
    def _linreg_endpoint(window):
        x = np.arange(period)
        slope, intercept = np.polyfit(x, window, 1)
        return intercept + slope * (period - 1)

    return close.rolling(window=period, min_periods=period).apply(
        _linreg_endpoint, raw=True
    )


def lsma_numpy(close: np.ndarray, period: int = 20) -> np.ndarray:
    """
    使用 numpy 手动实现 LSMA（含斜率输出）
    """
    n = len(close)
    result = np.full(n, np.nan)
    slopes = np.full(n, np.nan)

    x = np.arange(period, dtype=float)
    x_mean = x.mean()
    x_var = np.sum((x - x_mean) ** 2)

    for i in range(period - 1, n):
        window = close[i - period + 1 : i + 1]
        p_mean = window.mean()

        # 最小二乘法
        b = np.sum((x - x_mean) * (window - p_mean)) / x_var
        a = p_mean - b * x_mean

        result[i] = a + b * (period - 1)
        slopes[i] = b

    return result, slopes


def lsma_weights(period: int = 20) -> np.ndarray:
    """
    计算 LSMA 的等效权重向量
    """
    n = period
    i = np.arange(n)
    weights = 6 * (2 * i - n + 1) / (n * (n**2 - 1)) + 1 / n
    return weights


# ========== 使用示例 ==========
if __name__ == "__main__":
    np.random.seed(42)
    dates = pd.date_range("2024-01-01", periods=120, freq="D")
    price = 100 + np.cumsum(np.random.randn(120) * 0.8)

    df = pd.DataFrame({
        "date": dates,
        "open":  price + np.random.randn(120) * 0.3,
        "high":  price + np.abs(np.random.randn(120) * 0.6),
        "low":   price - np.abs(np.random.randn(120) * 0.6),
        "close": price,
        "volume": np.random.randint(1000, 10000, size=120),
    })
    df.set_index("date", inplace=True)

    # LSMA 与其他均线对比
    df["SMA_20"]  = df["close"].rolling(20).mean()
    df["EMA_20"]  = df["close"].ewm(span=20, adjust=False).mean()
    df["LSMA_20"] = lsma(df["close"], period=20)

    print("=== SMA vs EMA vs LSMA 对比 ===")
    print(df[["close", "SMA_20", "EMA_20", "LSMA_20"]].tail(10))

    # 获取斜率信息
    lsma_vals, slope_vals = lsma_numpy(df["close"].values, period=20)
    df["slope"] = slope_vals
    df["trend"] = np.where(slope_vals > 0, "UP",
                  np.where(slope_vals < 0, "DOWN", "FLAT"))

    print("\n=== LSMA 斜率与趋势方向 ===")
    print(df[["close", "LSMA_20", "slope", "trend"]].tail(10))

    # 显示 LSMA 权重
    w = lsma_weights(20)
    print("\n=== LSMA(20) 权重分布 ===")
    print(f"最旧数据权重: {w[0]:.4f}")
    print(f"中间数据权重: {w[10]:.4f}")
    print(f"最新数据权重: {w[19]:.4f}")
    print(f"权重之和: {w.sum():.6f}")
    print(f"负权重数量: {(w < 0).sum()}")

四、指标能解决的问题

1. 趋势方向的量化判断

LSMA 的斜率直接给出了趋势的方向和强度：

  • 斜率 > 0：窗口内价格呈上升趋势
  • 斜率 < 0：窗口内价格呈下降趋势
  • 斜率的绝对值：趋势的强度

2. 低滞后的趋势跟踪

由于 LSMA 取的是回归线的端点值（而非中心值），它本身具有一定的「外推」效果，使得在趋势中 LSMA 比 SMA 更贴近当前价格，滞后更低。

3. 趋势质量评估

结合 R-Squared（决定系数）使用，可以评估趋势的「质量」：

  • R-Squared 接近 1：价格高度线性，趋势可靠
  • R-Squared 接近 0：价格无明显线性趋势，信号不可靠

4. 回归通道

LSMA 可以与标准误差（Standard Error）结合，构成线性回归通道（Linear Regression Channel），类似于布林带但基于回归而非简单均值。

5. 均值回归策略

当价格偏离 LSMA 较远时，预期价格会回归至 LSMA 附近。这种均值回归特性可以用于：

  • 超买超卖判断
  • 配对交易的价差分析
  • 动态止盈止损
组合策略

LSMA + R-Squared 的组合是一个强大的趋势交易框架：

  1. R-Squared > 0.5 → 趋势有效
  2. LSMA 斜率 > 0 → 上升趋势，考虑做多
  3. 价格从上方回到 LSMA 附近 → 入场点

注意事项
  1. LSMA 在震荡市场中可能出现频繁穿越价格的情况，不宜单独作为入场信号。
  2. 当 R-Squared 很低时（< 0.2），LSMA 的端点值和斜率都不可靠，应暂停基于 LSMA 的交易。
  3. LSMA 的负权重特性意味着它的值可能短暂超过窗口内的最高价或低于最低价，这不是 bug 而是数学特性。
