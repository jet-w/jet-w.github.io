锯齿指标 (Zig Zag) — 金融量化指标教程

Haiyue
2025年12月20日
8分钟

一、什么是 Zig Zag 指标

锯齿指标（Zig Zag）是一种通过连接价格图表上的显著高点和低点来过滤市场噪声的技术分析工具。它使用一个百分比阈值（deviation）来忽略小幅波动，仅保留足够大的价格摆动（swings），从而在图表上绘制出清晰的锯齿形折线。

历史背景

Zig Zag 指标的确切发明者已难以考证，它是技术分析工具中较早出现的「过滤型」指标之一。该指标在 Arthur Merrill 的著作中被引用，并在 20 世纪 80-90 年代随着计算机化技术分析的普及而得到广泛使用。它被集成到了几乎所有主流的技术分析软件平台中（如 MetaTrader、TradingView、Bloomberg 等）。

Zig Zag 的广泛流行很大程度上归功于其在 Elliott Wave（艾略特波浪理论）分析中的应用——波浪理论实践者需要客观地识别价格的主要摆动点，Zig Zag 正好提供了这一功能。

指标分类

  • 类型：叠加指标（Overlay），绘制在价格图表上
  • 大类：其他叠加指标（Other Overlay）/ 过滤器
  • 默认参数：deviation = 5（价格变化超过 5% 才被视为有效摆动）
  • 数据要求：需要 High 和 Low 数据（或 Close 数据）
重要特性：Zig Zag 会重绘！

Zig Zag 是一个会重绘（repaint）的指标——它的最后一段线段可能随着新数据的到来而改变方向或位置。因此，Zig Zag 不能直接用于实时交易信号的生成。它的价值在于事后分析和辅助工具，而非预测。

二、数学原理与计算方法

核心思想

Zig Zag 算法的核心是：追踪价格运动的方向，当反向运动的幅度超过预设阈值时，记录一个转折点（pivot）并反转追踪方向。

算法参数

  • ddd：偏差阈值（deviation），默认为 5%
  • 数据源：通常使用 High（追踪上行时）和 Low（追踪下行时）

算法逻辑

核心循环逻辑：追踪当前趋势方向，若价格继续朝同方向运动则更新极值点；若反向运动幅度超过阈值 d%d\%d% 则确认前一个极值为 pivot 并反转方向。

数学条件

设当前趋势方向为上行，最近高点为 PhighP_{high}Phigh​，则反转条件为：

Phigh−LtPhigh×100≥d\frac{P_{high} - L_t}{P_{high}} \times 100 \geq dPhigh​Phigh​−Lt​​×100≥d

即从最近高点到当前最低价的下跌幅度达到或超过 d%d\%d%。

反之，若当前趋势方向为下行，最近低点为 PlowP_{low}Plow​，则反转条件为：

Ht−PlowPlow×100≥d\frac{H_t - P_{low}}{P_{low}} \times 100 \geq dPlow​Ht​−Plow​​×100≥d

重绘问题

Zig Zag 的最后一段线段是「暂定」的——市场继续朝当前方向运动时端点会不断更新，只有反转条件触发后上一段才被「确认」。在实时运行中，最后一段线可能随时改变。

关于 deviation 参数的选择
  • d=1%d = 1\%d=1%：非常敏感，标记几乎所有小幅波动，噪声多
  • d=5%d = 5\%d=5%：中等灵敏度，常用默认值
  • d=10%d = 10\%d=10%：仅标记大幅波动，适合长期趋势分析
  • d=20%d = 20\%d=20%：仅捕捉牛市/熊市级别的转折

参数选择取决于分析目的和时间框架。

三、Python 代码实现

import numpy as np
import pandas as pd

def zigzag(high: pd.Series, low: pd.Series,
           deviation: float = 5.0) -> pd.DataFrame:
    """
    计算 Zig Zag 指标

    Parameters
    ----------
    high : pd.Series
        最高价序列
    low : pd.Series
        最低价序列
    deviation : float
        反转阈值（百分比），默认为 5.0

    Returns
    -------
    pd.DataFrame
        包含以下列：
        - zigzag: 在 pivot 点处为价格值，其余为 NaN
        - pivot_type: 1 为高点 pivot，-1 为低点 pivot，0 为非 pivot
        - zigzag_line: 线性插值后的完整 Zig Zag 线
    """
    h = high.values.astype(float)
    l = low.values.astype(float)
    n = len(h)

    pivots = np.zeros(n)       # 0: 非 pivot, 1: 高点, -1: 低点
    pivot_prices = np.full(n, np.nan)

    # 初始化：用前两根 K 线确定初始方向
    if h[0] - l[1] > h[1] - l[0]:
        # 第一根高，第二根低 → 初始方向向下
        direction = -1
        last_high_idx = 0
        last_high_price = h[0]
        last_low_idx = 1
        last_low_price = l[1]
    else:
        direction = 1
        last_low_idx = 0
        last_low_price = l[0]
        last_high_idx = 1
        last_high_price = h[1]

    threshold = deviation / 100.0

    for i in range(2, n):
        if direction == 1:  # 当前追踪上行趋势
            if h[i] > last_high_price:
                # 继续上行，更新高点
                last_high_idx = i
                last_high_price = h[i]
            elif l[i] < last_high_price * (1 - threshold):
                # 反转：从高点下跌超过阈值
                pivots[last_high_idx] = 1
                pivot_prices[last_high_idx] = last_high_price
                direction = -1
                last_low_idx = i
                last_low_price = l[i]

        else:  # direction == -1, 当前追踪下行趋势
            if l[i] < last_low_price:
                # 继续下行，更新低点
                last_low_idx = i
                last_low_price = l[i]
            elif h[i] > last_low_price * (1 + threshold):
                # 反转：从低点上涨超过阈值
                pivots[last_low_idx] = -1
                pivot_prices[last_low_idx] = last_low_price
                direction = 1
                last_high_idx = i
                last_high_price = h[i]

    # 标记最后一个未确认的 pivot
    if direction == 1:
        pivots[last_high_idx] = 1
        pivot_prices[last_high_idx] = last_high_price
    else:
        pivots[last_low_idx] = -1
        pivot_prices[last_low_idx] = last_low_price

    # 构建线性插值的 Zig Zag 线
    zigzag_line = pd.Series(pivot_prices, index=high.index).interpolate()

    return pd.DataFrame({
        "zigzag": pd.Series(pivot_prices, index=high.index),
        "pivot_type": pd.Series(pivots, index=high.index, dtype=int),
        "zigzag_line": zigzag_line,
    })

if __name__ == "__main__":

四、指标能解决的问题

1. 过滤市场噪声

Zig Zag 的核心价值在于消除小幅波动，让分析师能清晰地看到价格的主要运动方向和转折点：

  • 5% 的 deviation 可以过滤掉日常的小幅涨跌
  • 调整 deviation 可以控制过滤的力度

2. 识别摆动高点和低点（Swing Points）

Zig Zag 自动标注的 pivot 点对应价格的摆动高点和摆动低点：

Pivot 类型含义
高点 Pivot一轮上涨的终点，可能是阻力位
低点 Pivot一轮下跌的终点，可能是支撑位

3. Elliott Wave 分析辅助

波浪理论需要识别价格的五浪推动和三浪调整结构。Zig Zag 通过以下方式辅助波浪计数：

  • 自动标记主要转折点，作为波浪起止点的候选
  • 通过调整 deviation 参数控制波浪的级别（大浪 vs 小浪）
  • 可计算每段摆动的幅度比例，辅助 Fibonacci 分析

4. 计算回撤比率

Zig Zag 标注的 pivot 点可以直接用于计算 Fibonacci 回撤比率：

Retracement=∣Swingend−Current∣∣Swingend−Swingstart∣Retracement = \frac{|Swing_{end} - Current|}{|Swing_{end} - Swing_{start}|}Retracement=∣Swingend​−Swingstart​∣∣Swingend​−Current∣​

常见的 Fibonacci 回撤水平（38.2%、50%、61.8%）可以基于 Zig Zag 的摆动自动计算。

5. 测量波段幅度

通过分析 Zig Zag 的摆动数据，可以统计平均上涨/下跌幅度、摆动持续时间和多空不对称性等市场结构特征。

tip 实战建议

  1. 永远不要将 Zig Zag 作为实时交易信号——它会重绘，最后一段线段是不可靠的。
  2. 在 Elliott Wave 分析中，通常需要多个 deviation 值的 Zig Zag 叠加使用，以识别不同级别的波浪。
  3. 使用已确认的 pivot 点计算 Fibonacci 回撤水平是一种高效的方法。
  4. 如果需要不重绘的替代品，考虑使用 Williams Fractal——它一旦确认就不会改变。
  5. 在回测中必须确保信号只依赖于「当时已确认」的 pivot，避免前视偏差。
