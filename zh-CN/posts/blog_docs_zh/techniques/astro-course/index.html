第 1 章：Astro 基础入门

学习目标：

  1. 理解 Astro 的核心概念和优势
  2. 掌握 Astro 项目初始化和基本配置
  3. 熟悉 Astro 文件结构和路由系统
  4. 了解静态站点生成 (SSG) 的工作原理

简要说明：从零开始了解 Astro 框架，建立对现代静态站点生成器的认知基础。

第 2 章：Astro 核心特性

学习目标：

  1. 掌握 Astro 组件语法和编写规范
  2. 理解 Islands Architecture 架构模式
  3. 学会使用 Astro 的内置组件和 API
  4. 熟练运用 frontmatter 和 props 传递

简要说明：深入学习 Astro 的核心功能，为后续集成第三方框架打下基础。

第 3 章：Vue 3 集成与配置

学习目标：

  1. 配置 Astro 项目支持 Vue 3
  2. 理解 Vue 组件在 Astro 中的生命周期
  3. 掌握客户端水合 (Hydration) 机制
  4. 学会在 Astro 中使用 Vue 3 的 Composition API

简要说明：将 Vue 3 无缝集成到 Astro 项目中，发挥两者的优势。

第 4 章：Tailwind CSS 样式系统

学习目标：

  1. 在 Astro 项目中配置和优化 Tailwind CSS
  2. 掌握响应式设计和样式组合技巧
  3. 学会自定义 Tailwind 配置和主题
  4. 实现组件级样式管理和复用
