Ralph Wiggum

Haiyue
January 18, 2025
1min
#AI coding #Anthropics

What is Ralph Wiggum

The Ralph Wiggum plugin intercepts Claude Code’s exit attempts and repeatedly provides prompt files to the AI agent.

How to Use

Step 1: Launch and Authorize

claude --dangerously-skip-permissions

Step 2: Add Plugin Marketplace

/plugin marketplace add anthropics/claude-code

Step 3: Install Plugin

/plugin install ralph-wiggum@claude-code-plugins

Step 4: Run Plugin

# Help documentation
/ralph-wiggum:help

# Cancel loop
/ralph-wiggum:cancel-raph

# Run loop
/ralph-wiggum:ralph-loop
Examples

/ralph-wiggum:ralph-loop "Create a beautiful blog homepage" --completion-promise "DONE"

/ralph-wiggum:ralph-loop "Optimize blog" --max-iterations 20
