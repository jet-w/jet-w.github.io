Chapter 2 3D Fundamentals and Coordinate Systems

Learning Objectives
  • Understand 3D space coordinate systems
  • Master object transformation operations (move, rotate, scale)
  • Learn object selection and edit modes
  • Understand local vs global coordinate systems
  • Master precision modeling tools and alignment features

Detailed Knowledge Points

2.1 3D Space Coordinate System

2.1.1 Cartesian Coordinate System

In 3D space, we use a three-dimensional Cartesian coordinate system to position objects:

Y axis (green)
↑
│
│
└────→ X axis (red)
/
/
Z axis (blue)

Axis Description:

  • X axis (red): Left-right direction, positive direction to the right
  • Y axis (green): Front-back direction, positive direction forward
  • Z axis (blue): Up-down direction, positive direction upward
Blender Coordinate System Characteristics
  • Blender uses a right-handed coordinate system
  • Z axis is the up direction (differs from some software using Y axis as up)
  • Origin (0, 0, 0) is located at the scene center

2.1.2 Coordinate System Types

Global Coordinate System:

  • Fixed world coordinate system
  • All objects are positioned relative to this system
  • Axis directions never change

Local Coordinate System:

  • Each object has its own coordinate system
  • Changes direction as object rotates
  • Convenient for operations relative to the object itself

View Coordinate System:

  • Coordinate system relative to the current view
  • Changes as viewport rotates
  • Convenient for operations from current viewing angle

2.2 Basic Transform Operations

2.2.1 Move Operation (Grab/Move)

Basic Move:

G         # Activate move tool, follows mouse
G + X     # Constrain to X axis movement
G + Y     # Constrain to Y axis movement
G + Z     # Constrain to Z axis movement

# Precise movement
G + X + 2   # Move 2 units along X axis
G + Y + -1  # Move 1 unit in negative Y direction

# Planar movement (exclude an axis)
G + Shift + Z  # Move in XY plane (exclude Z axis)
G + Shift + X  # Move in YZ plane (exclude X axis)

Move Practice Example:

# Create a simple scene layout
# 1. Keep default cube at origin
# 2. Add sphere: Shift + A → Mesh → UV Sphere
# 3. Move sphere: G + X + 3 (move 3 units to the right)
# 4. Add cylinder: Shift + A → Mesh → Cylinder
# 5. Move cylinder: G + Y + 3 (move 3 units forward)

2.2.2 Rotate Operation

Basic Rotation:

R         # Activate rotation tool
R + X     # Rotate around X axis
R + Y     # Rotate around Y axis
R + Z     # Rotate around Z axis

# Precise rotation
R + Z + 45  # Rotate 45 degrees around Z axis
R + X + 90  # Rotate 90 degrees around X axis

# Incremental rotation
R + R       # Repeat rotation by previous angle

Rotation Pivot:

Pivot PointShortcutDescription
Bounding Box Center. (period)Geometric center of selected object
3D CursorShift + .Use 3D cursor as rotation center
Individual OriginsCtrl + .Each rotates around own origin when multiple selected
Active ElementAlt + .Use last selected object as center

2.2.3 Scale Operation

Basic Scale:

S         # Uniform scale
S + X     # Scale along X axis
S + Y     # Scale along Y axis
S + Z     # Scale along Z axis

# Precise scale
S + 2     # Scale 2x larger
S + 0.5   # Scale to half size
S + -1    # Mirror flip

# Non-uniform scale
S + Shift + Z  # Scale in XY plane (doesn't affect Z)

2.3 Transform Tools and Gizmos

2.3.1 Transform Toolbar

In the toolbar on the left side of the 3D viewport:

┌─────────┐
│    ↗    │  Select tool (W)
├─────────┤
│    ✋   │  3D Cursor tool (Shift + Right-click)
├─────────┤
│    ↔    │  Move tool (G)
├─────────┤
│    ↻    │  Rotate tool (R)
├─────────┤
│    ⊞    │  Scale tool (S)
├─────────┤
│    ⚒    │  Transform tool (T)
└─────────┘

2.3.2 Gizmos

Gizmos are visual transformation tools in the viewport:

Move Gizmo:

  • Red arrow: X axis movement
  • Green arrow: Y axis movement
  • Blue arrow: Z axis movement
  • Colored squares: Planar movement

Rotate Gizmo:

  • Red ring: Rotate around X axis
  • Green ring: Rotate around Y axis
  • Blue ring: Rotate around Z axis
  • White outer ring: Free rotation

Scale Gizmo:

  • Colored squares: Uniform scale
  • Colored lines: Single axis scale

2.4 Precision Modeling Tools

2.4.1 Numeric Input

Precise Transform Input:

# Direct numeric input during transform operations
G + X + Tab  # Switch to numeric input mode
# Then input specific value, e.g.: 2.5

# Using expressions
S + Tab  # Enter numeric input
# Can input: *2 (multiply by 2) or /3 (divide by 3) or +1.5 (add 1.5)

2.4.2 Snapping Tool

Snap Settings:

# Enable/disable snapping
Shift + Tab  # Toggle snapping on/off

# Snap types (set in header bar)
- Increment: Grid snapping
- Vertex: Vertex snapping
- Edge: Edge snapping
- Face: Face snapping
- Volume: Volume snapping

Snap Options:

OptionDescriptionUse Case
ClosestSnap to closest targetGeneral purpose
CenterSnap to target centerAlignment operations
MedianSnap to median of selectionWhen multiple selected
ActiveSnap to active elementPrecise alignment

2.4.3 Proportional Editing

O  # Enable/disable proportional editing

# Proportional editing types
- Smooth: Smooth influence
- Sphere: Spherical influence
- Root: Root influence
- Sharp: Sharp influence
- Linear: Linear influence
- Constant: Constant influence

# Adjust influence range
Mouse scroll wheel  # Adjust influence radius in proportional edit mode

2.5 Coordinate System Switching

2.5.1 Transform Orientation

In the 3D viewport header bar, you can switch transform orientation:

Global              # Use world coordinate system
Local               # Use object local coordinate system
Normal              # Use face normal coordinate system
Gimbal              # Use gimbal coordinate system
View                # Use view coordinate system
Cursor              # Use 3D cursor coordinate system

2.5.2 Transform Pivot Point

Transform pivot point determines the center of transformation:

Pivot Point Types:

# Bounding Box Center
Use for: General transform operations

# 3D Cursor
Use for: Rotation around specific point

# Individual Origins
Use for: Transform multiple objects individually

# Median Point
Use for: Center point of multiple selected objects

# Active Element
Use for: Use last selected as reference

2.6 Advanced Selection Tools

2.6.1 Selection Tools

Basic Selection:

A          # Select all
Alt + A    # Deselect all
Ctrl + I   # Invert selection
H          # Hide selected
Alt + H    # Show all
Shift + H  # Hide unselected

Box and Circle Select:

B          # Box select tool
C          # Circle select tool (scroll wheel adjusts size)
Alt + B    # Box select view clipping

2.6.2 Select Similar

Shift + G  # Select similar
- Type: Select by type
- Material: Select by material
- Color: Select by color
- Dimensions: Select by dimensions

2.7 3D Cursor and Origin

2.7.1 3D Cursor

The 3D cursor is a positioning tool in the scene:

Shift + Right-click  # Place 3D cursor
Shift + S            # Snap menu
- Cursor to Selected: Cursor to selected
- Selection to Cursor: Selected to cursor
- Cursor to Center: Cursor to center
- Cursor to Grid: Cursor to grid

2.7.2 Origin Operations

# Set origin location
Ctrl + Alt + Shift + C  # Origin menu
- Geometry to Origin: Geometry to origin
- Origin to Geometry: Origin to geometry center
- Origin to 3D Cursor: Origin to cursor
- Origin to Center of Mass: Origin to center of mass

2.8 Practical Exercises

Exercise 1: Understanding Coordinate Systems

Exercise Objective

Understand the differences and application scenarios of different coordinate systems

# 1. Create three cubes
# 2. Arrange them in an L shape
# 3. Rotate the middle cube 45 degrees
# 4. Move the rotated cube in both global and local coordinate systems
# 5. Observe the operational differences

Steps:
1. Delete default cube
2. Shift + A add cube, position (0, 0, 0)
3. Shift + D duplicate, move to (2, 0, 0)
4. Shift + D duplicate again, move to (0, 2, 0)
5. Select cube at position (2, 0, 0)
6. R + Z + 45 rotate 45 degrees
7. Switch coordinate system in header bar, observe gizmo changes
8. Move this cube using both global and local coordinate systems

Exercise 2: Precision Modeling Practice

# Create a simple table model
# Requirements: Table top 2x1x0.1, legs height 0.8

# Table top creation
1. Add cube
2. S + X + 1 (scale to 2 along X axis)
3. S + Y + 0.5 (scale to 1 along Y axis)
4. S + Z + 0.05 (scale to 0.1 along Z axis)
5. G + Z + 0.45 (move up to appropriate position)

# Table leg creation
6. Add cube for table leg
7. S + X + 0.05, S + Y + 0.05 (shrink X, Y)
8. S + Z + 0.4 (scale Z to 0.8 height)
9. G + X + 0.8, G + Y + 0.4 (move to table corner)
10. Shift + D duplicate other three legs

Exercise 3: Comprehensive Transform Tool Application

Notes
  • Ensure understanding of global vs local coordinate system differences
  • Proficiently use numeric input for precise transforms
  • Properly use pivot point settings
# Create a windmill model
# 1. Create windmill blade (using plane)
# 2. Duplicate and rotate to create multiple blades
# 3. Create support post
# 4. Combine into complete model

Detailed steps:
1. Delete default cube
2. Shift + A → Mesh → Plane
3. S + Y + 2 (stretch plane as blade)
4. Set pivot point to 3D cursor
5. Shift + S → Cursor to Center (cursor to center)
6. Shift + D duplicate blade
7. R + Z + 90 (rotate 90 degrees)
8. Repeat steps 6-7 to create 4 blades
9. Add cylinder as support post
10. G + Z + -1 (move down)
11. S + Z + 2 (stretch post)

Transform Tool Settings

2.9 Transform Settings Panel

In the transform tab of the properties panel:

Location:

  • X, Y, Z coordinate values
  • Can directly input precise values

Rotation:

  • Euler angles: X, Y, Z axis rotation angles
  • Axis-angle: Rotation axis and angle
  • Quaternion: Four-dimensional rotation representation

Scale:

  • X, Y, Z axis scale factors
  • Link icon: Maintain proportional scaling

2.10 Object Relationships and Hierarchy

2.10.1 Parent-Child Relationships

# Establish parent-child relationship
1. First select child object
2. Then select parent object (Shift + left-click)
3. Ctrl + P → Object (keep transform)

# Clear parent-child relationship
Alt + P → Clear Parent

Parent-Child Relationship Characteristics:

  • Child objects follow parent transformations
  • Child object coordinates are relative to parent
  • Forms hierarchical structure for easy management

2.10.2 Collection Management

# Create collection
M  # Move to collection menu
Shift + A  # Create new collection

# Collection operations
- Hide/show collection
- Enable/disable collection selection
- Collection instancing
Learning Suggestions
  1. Understand Coordinate Systems: Difference between global and local coordinate systems is fundamental to 3D work
  2. Master Transform Operations: G, R, S three basic operations must be very proficient
  3. Master Precise Control: Learn to use numeric input and snapping tools
  4. Develop Spatial Thinking: Observe and operate objects from different angles
  5. Use Helper Tools: 3D cursor, proportional editing can greatly improve efficiency

Through this chapter, you should be able to:

  • Understand basic 3D space concepts
  • Proficiently use various transform tools
  • Precisely control object position, rotation, and scale
  • Understand application scenarios for different coordinate systems

These skills are the foundation for all subsequent 3D operations and must be mastered proficiently.
