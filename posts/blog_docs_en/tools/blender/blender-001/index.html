Chapter 1 Getting Started with Blender

Learning Objectives
  • Understand Blender software overview and application areas
  • Master Blender interface layout and basic operations
  • Learn basic navigation and view controls
  • Understand Blender workflow concepts
  • Master file management and project settings

Detailed Knowledge Points

1.1 Blender Software Overview

1.1.1 What is Blender

Blender is a fully-featured open source 3D creation suite that supports the entire 3D pipeline: modeling, sculpting, animation, simulation, rendering, compositing, and motion tracking. It also features video editing and game creation capabilities.

Core Features:

  • Completely free and open source
  • Cross-platform support (Windows, macOS, Linux)
  • Active development community
  • Regular updates and feature improvements
  • No restrictions on commercial use

1.1.2 Application Areas

Application AreaSpecific UsesExamples
Film ProductionVFX, animation, modelingPartial scenes from “Spider-Man: Into the Spider-Verse”
Game DevelopmentCharacter modeling, scene creation, animationIndie game development
Architectural VisualizationArchitectural rendering, interior designArchitecture design previews
Product DesignIndustrial design, product presentationProduct prototype displays
Education & Training3D teaching, scientific visualizationEducational animation production

1.2.2 Main Editor Introduction

3D Viewport:

  • Main working area
  • Displays 3D scene
  • Supports multiple shading modes
  • Provides various selection and transformation tools

Outliner:

  • Displays scene hierarchy structure
  • Manages object visibility and selection state
  • Organizes scene elements

Properties Panel:

  • Shows detailed settings for selected objects
  • Contains multiple sub-panels (object, material, render, etc.)
  • Provides parameter adjustment functions

Shader Editor:

  • Create and edit materials
  • Node-based workflow
  • Supports complex material creation

1.3 Basic Navigation and View Controls

1.3.1 Viewport Navigation

Mouse Operation Rules

Blender uses a three-button mouse operation mode:

  • Left button: Select objects
  • Middle button: Viewport navigation (rotate, zoom, pan)
  • Right button: Pop-up context menu

Basic Navigation Operations:

View Rotation: Middle mouse drag
View Zoom: Scroll wheel
View Pan: Shift + Middle mouse drag

Numpad Shortcuts:
- 1: Front view
- 3: Right view
- 7: Top view
- 0: Camera view
- 5: Orthographic/Perspective toggle
- . (period): Focus on selected object

1.3.2 Selection Operations

Selection Methods:

  • Click Selection: Left-click on object
  • Box Select: B key to activate, drag to select area
  • Lasso Select: Ctrl + left-click drag
  • Select All/Deselect All: A key / Alt + A

Multiple Selection Operations:

Shift + Left-click: Add to selection
Shift + Right-click: Remove from selection
Ctrl + I: Invert selection

1.4 Basic Object Operations

1.4.1 Adding Objects

Adding Basic Primitives:

Shift + A: Open Add menu
- Mesh
  - Cube
  - UV Sphere
  - Cylinder
  - Plane
  - etc...

1.4.2 Transform Operations

Basic Transform Tools:

OperationShortcutDescription
Move (Grab)GMove object position
RotateRRotate object
ScaleSChange object size

Constrained Axis Operations:

# Example: Precise move operations
G + X + 2  # Move 2 units along X axis
R + Z + 45 # Rotate 45 degrees around Z axis
S + Y + 2  # Scale 2x along Y axis

# Constrain to plane
G + Shift + Z  # Move in XY plane (exclude Z axis)

1.4.3 Delete and Undo

Delete Operations:
- Delete/X: Delete selected object
- Ctrl + Z: Undo
- Ctrl + Shift + Z: Redo

1.5 Edit Mode Basics

1.5.1 Edit Mode Switching

Tab: Toggle between Object Mode and Edit Mode
Ctrl + Tab: Quick switch edit mode type

Selection Types in Edit Mode:

  • Vertex Mode: Select and edit vertices
  • Edge Mode: Select and edit edges
  • Face Mode: Select and edit faces

1.5.2 Basic Edit Operations

Extrude Operation:

# Extrude selected face
E  # Activate extrude tool
# Then move mouse to position new location
# Left-click to confirm, right-click to cancel

# Example: Creating a simple house
# 1. Add cube
# 2. Enter Edit Mode (Tab)
# 3. Select top face (Alt + 3 to switch to face select mode)
# 4. Press E to extrude top face
# 5. Press S to scale to appropriate size for roof

1.6.2 Interface Customization

Split Editor:

Right-click on editor border → Split Area
Drag to create new editor area

Merge Editor:

Right-click on editor border → Join Area
Select the editor to keep

1.7 File Management

1.7.1 File Operations

Basic File Operations:

Ctrl + N: New file
Ctrl + O: Open file
Ctrl + S: Save file
Ctrl + Shift + S: Save as
Ctrl + Z: Undo

1.7.2 Project Management Best Practices

Project Organization Suggestions
Project Folder Structure:
MyProject/
├── Blends/          # Blender files
├── Textures/        # Texture files
├── References/      # Reference images
├── Renders/         # Render output
└── Assets/          # Other resources

File Save Settings:

# Enable auto-save (in user preferences)
File → Preferences → Save & Load
- Auto Save Temporary Files: Enable
- Timer (minutes): Set auto-save interval

1.8 Preferences

1.8.1 Important Settings

Input Settings:

Edit → Preferences → Input
- Select With: Choose left or right mouse button
- Emulate 3 Button Mouse: Emulate three-button mouse
- Emulate Numpad: Emulate numpad

Theme Settings:

Edit → Preferences → Themes
- Choose different interface themes
- Customize color schemes

Add-on Management:

Edit → Preferences → Add-ons
- Enable/disable built-in add-ons
- Install third-party add-ons

1.9 Practical Exercises

Exercise 1: Interface Familiarization

Exercise Steps
  1. Open Blender and familiarize yourself with the default interface
  2. Practice using mouse navigation (rotate, zoom, pan)
  3. Use numpad to switch between different views
  4. Practice selecting and deselecting the default cube
  5. Try switching between different workspaces

Exercise 2: Basic Modeling Practice

# Creating a simple snowman
# Steps:
# 1. Delete default cube (Delete key)
# 2. Add UV Sphere for body (Shift + A → Mesh → UV Sphere)
# 3. Duplicate sphere for head (Shift + D)
# 4. Scale head and move to appropriate position (S to scale, G to move)
# 5. Add smaller spheres for eyes and nose
# 6. Save file (Ctrl + S)

Exercise 3: Basic Edit Practice

Notes

In Edit Mode:

  • Ensure correct component type is selected (vertex/edge/face)
  • Extrude operations need to move to new position
  • Frequently use Tab key to toggle between Object and Edit modes
# Creating a simple house model
# 1. Start with cube
# 2. Enter Edit Mode (Tab)
# 3. Select top face
# 4. Extrude top face (E)
# 5. Inset face (I) to create roof edge
# 6. Extrude to create roof
# 7. Add doors and windows (delete faces, extrude inward)

Learning Suggestions
  1. Practice Navigation: Proficient viewport navigation is the foundation of 3D work
  2. Memorize Shortcuts: Shortcuts can significantly improve work efficiency
  3. Understand Mode Switching: The difference between Object Mode and Edit Mode is important
  4. Establish Good Habits: Save regularly, organize file structure properly
  5. Progress Gradually: Don’t rush, building a solid foundation is important

Through this chapter, you should be able to:

  • Proficiently navigate the Blender interface
  • Understand basic 3D operation concepts
  • Complete simple object creation and editing
  • Establish good working habits

These basic skills will lay a solid foundation for more advanced learning ahead.
