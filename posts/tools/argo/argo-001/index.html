知识点

什么是Argo

Argo是一套开源的云原生工具集，专为Kubernetes设计，用于运行和管理工作流、GitOps持续交付、渐进式部署和事件驱动自动化。由Intuit公司开发并捐赠给CNCF（云原生计算基金会），现为CNCF毕业项目。

Argo CD - GitOps引擎

核心价值

Argo CD实现了GitOps的核心理念：Git作为唯一真相源。它持续监控Git仓库中的Kubernetes清单，自动将集群状态与Git中的期望状态保持一致。

🔄 正在渲染 Mermaid 图表...
flowchart LR
    subgraph Traditional["传统CI/CD"]
        CI1[CI系统] -->|kubectl apply| K8s1[Kubernetes]
        Note1[推模式：CI推送到集群<br/>需要集群凭证]
    end

    subgraph GitOps["GitOps模式"]
        Dev[开发者] -->|git push| Git[Git仓库]
        ArgoCD[Argo CD] -->|监控| Git
        ArgoCD -->|同步| K8s2[Kubernetes]
        Note2[拉模式：集群拉取配置<br/>无需外部凭证]
    end

主要特性

特性说明
声明式配置使用Git管理应用配置，支持Kustomize、Helm、Jsonnet
自动同步检测配置变更，自动同步到集群
自我修复集群状态漂移时自动恢复
多集群从单一界面管理多个Kubernetes集群
SSO集成支持OIDC、LDAP、SAML等认证方式
RBAC细粒度的权限控制
审计日志完整的操作审计追踪

Argo Workflows - 工作流引擎

核心价值

Argo Workflows是Kubernetes原生的工作流引擎，每个步骤都运行在独立的容器中。适用于CI/CD流水线、数据处理、机器学习管道等场景。

Argo Rollouts - 渐进式交付

核心价值

Argo Rollouts提供高级部署能力，包括金丝雀发布、蓝绿部署、A/B测试等，结合自动化分析实现安全可控的应用发布。

发布策略对比

策略特点适用场景

安装准备

环境要求

# 基础环境要求
Kubernetes版本: >= 1.22
kubectl版本: 匹配集群版本
Helm版本: >= 3.0 (可选)

# 资源要求（每个组件）
Argo CD:
  CPU: 500m - 2核
  Memory: 512Mi - 2Gi
  Storage: 用于Redis缓存

Argo Workflows:
  CPU: 500m - 1核
  Memory: 256Mi - 1Gi
  Storage: 用于Artifact存储

Argo Rollouts:
  CPU: 100m - 500m
  Memory: 128Mi - 256Mi

Argo Events:
  CPU: 100m - 500m
  Memory: 128Mi - 512Mi

快速体验

# 创建命名空间
kubectl create namespace argocd
kubectl create namespace argo

# 安装Argo CD
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

# 安装Argo Workflows
kubectl apply -n argo -f https://github.com/argoproj/argo-workflows/releases/latest/download/install.yaml

# 安装Argo Rollouts
kubectl create namespace argo-rollouts
kubectl apply -n argo-rollouts -f https://github.com/argoproj/argo-rollouts/releases/latest/download/install.yaml

# 安装Argo Events
kubectl create namespace argo-events
kubectl apply -f https://raw.githubusercontent.com/argoproj/argo-events/stable/manifests/install.yaml

# 验证安装
kubectl get pods -n argocd
kubectl get pods -n argo
kubectl get pods -n argo-rollouts
kubectl get pods -n argo-events

brew install argocd

curl -sSL -o argocd https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
chmod +x argocd && sudo mv argocd /usr/local/bin/

# Argo Workflows CLI
# macOS
brew install argo

# Linux
curl -sLO https://github.com/argoproj/argo-workflows/releases/latest/download/argo-linux-amd64.gz
gunzip argo-linux-amd64.gz && chmod +x argo-linux-amd64 && sudo mv argo-linux-amd64 /usr/local/bin/argo

# Argo Rollouts kubectl插件
# macOS
brew install argoproj/tap/kubectl-argo-rollouts

# Linux
curl -LO https://github.com/argoproj/argo-rollouts/releases/latest/download/kubectl-argo-rollouts-linux-amd64
chmod +x kubectl-argo-rollouts-linux-amd64 && sudo mv kubectl-argo-rollouts-linux-amd64 /usr/local/bin/kubectl-argo-rollouts

# 验证CLI
argocd version
argo version
kubectl argo rollouts version
