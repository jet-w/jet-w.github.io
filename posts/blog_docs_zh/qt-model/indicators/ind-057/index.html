成交量 (Volume)

Haiyue
April 1, 2026
7min

一、什么是成交量指标

成交量（Volume）是金融市场中最基础、最古老也是最重要的技术指标之一。它记录了在特定时间段内某一金融资产被买卖的总数量（股数、合约数或手数等）。成交量的概念几乎与交易所的历史一样悠久——自有组织的金融交易存在以来，成交量就是交易记录的基本组成部分。

成交量属于**基础成交量（Basic Volume）**类指标，不需要任何参数设定。它通常以柱状图的形式显示在价格图表下方，每根柱子代表对应时间段的交易量。在大多数图表工具中，成交量柱通过颜色区分涨跌：

  • 绿色（或空心）柱：收盘价高于开盘价（阳线/上涨日）
  • 红色（或实心）柱：收盘价低于开盘价（阴线/下跌日）
Tip

华尔街有一句经典格言：“成交量是价格的先行指标”（Volume leads price）。几乎所有的价格变动都需要成交量来确认——没有成交量配合的价格变动往往缺乏持续性。

成交量本身不是一个”计算型”指标，而是市场的原始数据。然而，对成交量的分析方法和衍生技术却极为丰富，构成了技术分析中一个重要的分支领域。

二、数学原理与计算方法

2.1 基本定义

成交量的定义非常直观：

Vt=在时间段 t 内完成的全部交易数量V_t = \text{在时间段 } t \text{ 内完成的全部交易数量}Vt​=在时间段 t 内完成的全部交易数量

无需任何公式转换，它是直接从交易所获取的原始数据。

2.2 常用衍生计算

虽然成交量本身无需计算，但以下几种常见的衍生指标可以更好地分析成交量：

成交量移动平均线（Volume MA）：

VMAt=1n∑i=0n−1Vt−iVMA_t = \frac{1}{n} \sum_{i=0}^{n-1} V_{t-i}VMAt​=n1​i=0∑n−1​Vt−i​

通常使用 20 日 SMA，用于判断当前成交量是”放量”还是”缩量”。

相对成交量（Relative Volume, RVOL）：

RVOLt=VtVMAtRVOL_t = \frac{V_t}{VMA_t}RVOLt​=VMAt​Vt​​

RVOL>1RVOL > 1RVOL>1 表示当日成交量高于近期平均水平（放量），RVOL<1RVOL < 1RVOL<1 表示缩量。

成交量变化率（Volume Rate of Change）：

VROCt=Vt−Vt−nVt−n×100%VROC_t = \frac{V_t - V_{t-n}}{V_{t-n}} \times 100\%VROCt​=Vt−n​Vt​−Vt−n​​×100%

衡量成交量相对于 nnn 日前的变化百分比。

Note

部分图表软件使用”收盘价与前日收盘价”而非”收盘价与当日开盘价”来决定颜色。两种方式各有优劣——前者反映相对于前一交易日的变化，后者反映当日的多空方向。

三、Python 代码实现

import numpy as np
import pandas as pd


def volume_analysis(open_price: pd.Series, close: pd.Series,
                    volume: pd.Series,
                    ma_period: int = 20) -> pd.DataFrame:
    """
    成交量分析工具：计算成交量颜色、移动平均线、相对成交量等。

    参数:
        open_price : 开盘价序列
        close      : 收盘价序列
        volume     : 成交量序列
        ma_period  : 移动平均周期，默认 20

    返回:
        DataFrame 包含 volume, color, vol_ma, rvol, vol_spike 列
    """
    # 1. 涨跌着色
    color = pd.Series(
        np.where(close > open_price, 'green',
                 np.where(close < open_price, 'red', 'gray')),
        index=close.index
    )

    # 2. 成交量移动平均线
    vol_ma = volume.rolling(window=ma_period).mean()

    # 3. 相对成交量 (RVOL)
    rvol = volume / vol_ma.replace(0, np.nan)

    # 4. 成交量变化率
    vroc = volume.pct_change(periods=ma_period) * 100

    # 5. 成交量突增标记（RVOL > 2 视为突增）
    vol_spike = rvol > 2.0

    return pd.DataFrame({
        'volume': volume,
        'color': color,
        'vol_ma': vol_ma,
        'rvol': rvol,
        'vroc': vroc,
        'vol_spike': vol_spike
    })


def volume_profile(close: pd.Series, volume: pd.Series,
                   n_bins: int = 20) -> pd.DataFrame:
    """
    计算简化版成交量分布（Volume Profile）。

    参数:
        close  : 收盘价序列
        volume : 成交量序列
        n_bins : 价格区间数量，默认 20

    返回:
        DataFrame 包含 price_range, total_volume 列
    """
    price_min, price_max = close.min(), close.max()
    bins = np.linspace(price_min, price_max, n_bins + 1)
    labels = [f"{bins[i]:.2f}-{bins[i+1]:.2f}" for i in range(n_bins)]

    price_bin = pd.cut(close, bins=bins, labels=labels, include_lowest=True)
    profile = volume.groupby(price_bin).sum()

    return pd.DataFrame({
        'price_range': profile.index,
        'total_volume': profile.values
    })


# ============ 使用示例 ============
if __name__ == '__main__':
    np.random.seed(42)
    n_days = 100

    # 生成模拟 OHLCV 数据
    base_price = 50 + np.cumsum(np.random.randn(n_days) * 0.5)
    df = pd.DataFrame({
        'open':   base_price + np.random.randn(n_days) * 0.3,
        'high':   base_price + np.abs(np.random.randn(n_days) * 0.8),
        'low':    base_price - np.abs(np.random.randn(n_days) * 0.8),
        'close':  base_price + np.random.randn(n_days) * 0.2,
        'volume': np.random.randint(50000, 500000, n_days).astype(float)
    })

    # 成交量分析
    va = volume_analysis(df['open'], df['close'], df['volume'], ma_period=20)
    result = pd.concat([df[['open', 'close']], va], axis=1)

    print("=== 成交量分析结果（最后 15 行）===")
    cols = ['close', 'volume', 'color', 'vol_ma', 'rvol']
    print(result[cols].tail(15).to_string())

    # 成交量突增日统计
    spikes = result[result['vol_spike'] == True]
    print(f"\n=== 成交量突增日（RVOL > 2.0）：共 {len(spikes)} 天 ===")
    if len(spikes) > 0:
        print(spikes[['close', 'volume', 'rvol']].to_string())

    # 成交量分布
    print("\n=== 成交量分布（Volume Profile）===")
    vp = volume_profile(df['close'], df['volume'], n_bins=10)
    print(vp.to_string(index=False))

    # 量价关系统计
    up_days = result[result['color'] == 'green']
    down_days = result[result['color'] == 'red']
    print(f"\n=== 量价统计 ===")
    print(f"上涨日平均成交量: {up_days['volume'].mean():,.0f}")
    print(f"下跌日平均成交量: {down_days['volume'].mean():,.0f}")
    ratio = up_days['volume'].mean() / down_days['volume'].mean()
    print(f"涨/跌日成交量比: {ratio:.2f}")

四、指标能解决的问题

4.1 趋势确认——量价配合

成交量分析最核心的功能是确认价格走势的可信度：

  • 上涨 + 放量：多头力量强劲，上涨趋势可靠
  • 上涨 + 缩量：上涨缺乏买方支撑，可能是假突破或弱势反弹
  • 下跌 + 放量：空头力量强劲，下跌趋势可靠
  • 下跌 + 缩量：卖压减弱，下跌可能接近尾声

4.2 突破确认

当价格突破关键支撑或阻力位时，成交量是判断突破有效性的最重要工具：

  • 放量突破：突破伴随成交量显著放大（RVOL > 1.5），突破可靠
  • 缩量突破：突破时成交量低于平均水平，很可能是假突破
Warning

“放量突破”是技术分析中最强大的确认信号之一，但反过来”缩量突破即假突破”并不总是成立。某些情况下（如节假日前后、市场极度恐慌时），低成交量也可能出现有效突破。

4.3 反转预警

成交量异常通常预示着市场可能发生转折：

  • 恐慌性放量：在下跌末段出现成交量急剧放大（RVOL > 3），往往是”投降式抛售”（capitulation），可能标志着底部
  • 天量见天价：在上涨末段出现历史级别的成交量放大，可能标志着顶部
  • 地量见地价：成交量萎缩到极低水平，市场可能即将选择方向

4.4 成交量分析技术

  1. 成交量分布（Volume Profile）：统计各价格水平对应的总成交量，高成交量区域称为”价值区”（Value Area），常构成重要支撑/阻力
  2. 量价关系四象限分析：将涨/跌与放量/缩量组合为四种状态，判断市场健康程度
  3. 成交量移动平均比较：将当前成交量与 20/50/200 日移动平均进行比较
  4. 累积成交量：在日内交易中，跟踪累积成交量的分布特征

4.5 典型交易策略

  1. 放量突破策略：在价格突破关键位时，仅在成交量放大（RVOL > 1.5）时入场
  2. 缩量回调策略：在上涨趋势中，价格回调但成交量萎缩时买入
  3. 成交量突增（Volume Spike）策略：成交量突然放大 2 倍以上时关注方向性机会
  4. 成交量分布策略：在 Volume Profile 的高量区域（POC, Point of Control）附近交易

五、优缺点与适用场景

优点

优点说明
最基础的市场数据直接反映市场参与度和活跃程度，无计算偏差
通用性极强几乎所有市场、所有时间框架都可使用
不可操纵性（相对）虽然庄家可以制造假价格信号，但大规模操纵成交量的成本更高
领先性成交量变化常先于价格变化出现
无参数优化问题原始数据本身不需要参数设定，避免过拟合

缺点

缺点说明
需要标准化交易所数据外汇市场等场外交易无集中成交量数据
信息单一仅反映交易总量，不区分买方和卖方主动发起的交易
时间分辨率依赖日线成交量无法反映日内的成交量分布
跨品种不可直接比较不同股票的流通股数量不同，绝对成交量无法横向比较
算法交易影响高频交易和量化策略可能使成交量信号的传统解读方式失效

适用场景

  • 最适合：确认价格突破和趋势强度；检测市场参与度的异常变化
  • 较适合：与几乎所有其他技术指标配合使用，作为通用的确认工具
  • 不适合：外汇现货市场（无集中交易所成交量）；缺乏流动性的小市值品种

与衍生成交量指标比较

指标基础/衍生特点
Volume基础数据最原始的交易量信息
OBV衍生——累积将方向与成交量结合的趋势指标
A/D Line衍生——加权累积用日内位置加权成交量
MFI衍生——振荡器量价综合的超买超卖指标
CMF衍生——周期平均有界的买卖压力指标
VWAP衍生——加权均价成交量加权平均价格
Tip

实战建议：成交量分析的核心原则可以归纳为三句话：（1）成交量确认趋势——量价同向是健康的；（2）成交量预警反转——极端放量或极端缩量往往出现在转折点；（3）没有成交量就没有信心——任何缺乏成交量配合的价格变动都应该打折扣。养成在所有交易决策中检查成交量的习惯，它是最容易被忽视却最有价值的辅助工具。
