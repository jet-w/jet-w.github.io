三重指数平滑移动平均 (TRIX)

Haiyue
April 1, 2026
6min

一、什么是 TRIX 指标

TRIX（Triple Exponential Average，三重指数平滑移动平均）是一种动量振荡指标，通过对收盘价进行三次指数移动平均（EMA）平滑后计算其变化率来衡量价格动量。由于三重 EMA 的层层过滤效果，TRIX 能够有效消除短期价格噪声，只保留最显著的趋势变化信号。

历史背景

TRIX 由 Jack Hutson 于 1983 年发明，发表于《Technical Analysis of Stocks and Commodities》杂志。Hutson 正是这本杂志的创始人和编辑。他设计 TRIX 的初衷是创造一个能够过滤掉「无意义的价格波动」的指标，只在发生真正有意义的趋势变化时才给出信号。三重 EMA 的设计灵感来自于信号处理中的多级低通滤波器概念。

指标分类

  • 类型：振荡指标（Oscillator），独立面板显示
  • 大类：动量指标（Momentum）
  • 默认参数：周期 n=15n = 15n=15
  • 取值范围：无界，围绕零轴波动（单位：%）
TRIX 的过滤效果

单次 EMA 平滑只能部分消除噪声；两次 EMA（DEMA 的基础）进一步平滑；三次 EMA 则将短期波动几乎完全过滤掉。TRIX 再对三重 EMA 取变化率，相当于对已经高度平滑的数据做「速度」分析。

二、数学原理与计算方法

核心公式

第一步：计算三重 EMA

EMA1t=EMA(Close,n)tEMA1_t = EMA(Close, n)_tEMA1t​=EMA(Close,n)t​

EMA2t=EMA(EMA1,n)tEMA2_t = EMA(EMA1, n)_tEMA2t​=EMA(EMA1,n)t​

EMA3t=EMA(EMA2,n)tEMA3_t = EMA(EMA2, n)_tEMA3t​=EMA(EMA2,n)t​

第二步：计算 TRIX（变化率）

TRIXt=EMA3t−EMA3t−1EMA3t−1×100TRIX_t = \frac{EMA3_t - EMA3_{t-1}}{EMA3_{t-1}} \times 100TRIXt​=EMA3t−1​EMA3t​−EMA3t−1​​×100

可选：信号线

Signalt=SMA(TRIX,s)tSignal_t = SMA(TRIX, s)_tSignalt​=SMA(TRIX,s)t​

其中 sss 通常为 9。

EMA 的递推公式

EMAt=α⋅Xt+(1−α)⋅EMAt−1,α=2n+1EMA_t = \alpha \cdot X_t + (1 - \alpha) \cdot EMA_{t-1}, \quad \alpha = \frac{2}{n + 1}EMAt​=α⋅Xt​+(1−α)⋅EMAt−1​,α=n+12​

逐步计算逻辑

  1. 计算第一重 EMA：对收盘价做 nnn 周期 EMA
  2. 计算第二重 EMA：对第一重 EMA 再做 nnn 周期 EMA
  3. 计算第三重 EMA：对第二重 EMA 再做 nnn 周期 EMA
  4. TRIX = 三重 EMA 的百分比变化率
  5. 可选：计算 9 周期 SMA 作为信号线

三重 EMA 的平滑效果

对于周期 n=15n = 15n=15 的三重 EMA：

  • 等效平滑周期约为 3×(n−1)+1=433 \times (n-1) + 1 = 433×(n−1)+1=43 期
  • 相当于一个非常平滑的低通滤波器，只有持续数周的价格变动才能显著影响 TRIX 值
TRIX vs TEMA

注意区分 TRIX 和 TEMA（Triple Exponential Moving Average）：

  • TRIX = 三重 EMA 的变化率（振荡指标）
  • TEMA = 3⋅EMA1−3⋅EMA2+EMA33 \cdot EMA1 - 3 \cdot EMA2 + EMA33⋅EMA1−3⋅EMA2+EMA3（叠加指标） 两者使用相同的三重 EMA 中间产物，但最终的计算方式和用途完全不同。

三、Python 代码实现

import numpy as np
import pandas as pd


def trix(close: pd.Series,
         period: int = 15,
         signal_period: int = 9) -> pd.DataFrame:
    """
    计算 TRIX 指标

    Parameters
    ----------
    close : pd.Series
        收盘价序列
    period : int
        EMA 周期，默认 15
    signal_period : int
        信号线 SMA 周期，默认 9

    Returns
    -------
    pd.DataFrame
        包含 TRIX 和 Signal 两列
    """
    # 三重 EMA
    ema1 = close.ewm(span=period, adjust=False).mean()
    ema2 = ema1.ewm(span=period, adjust=False).mean()
    ema3 = ema2.ewm(span=period, adjust=False).mean()

    # TRIX = 三重 EMA 的百分比变化
    trix_values = (ema3 - ema3.shift(1)) / ema3.shift(1) * 100

    # 信号线
    signal_line = trix_values.rolling(window=signal_period, min_periods=signal_period).mean()

    return pd.DataFrame({
        "TRIX": trix_values,
        "Signal": signal_line
    }, index=close.index)


# ========== 使用示例 ==========
if __name__ == "__main__":
    np.random.seed(42)
    dates = pd.date_range("2024-01-01", periods=150, freq="D")
    trend = np.linspace(0, 15, 150)
    noise = np.cumsum(np.random.randn(150) * 0.8)
    price = 100 + trend + noise

    df = pd.DataFrame({
        "date": dates,
        "open":  price + np.random.randn(150) * 0.3,
        "high":  price + np.abs(np.random.randn(150) * 0.6),
        "low":   price - np.abs(np.random.randn(150) * 0.6),
        "close": price,
        "volume": np.random.randint(1000, 10000, size=150),
    })
    df.set_index("date", inplace=True)

    # 计算 TRIX
    trix_df = trix(df["close"], period=15, signal_period=9)
    df = pd.concat([df, trix_df], axis=1)

    print("=== TRIX 计算结果（最后 15 行）===")
    print(df[["close", "TRIX", "Signal"]].tail(15).to_string())

    # 零轴交叉
    df["zero_cross_up"] = (df["TRIX"] > 0) & (df["TRIX"].shift(1) <= 0)
    df["zero_cross_down"] = (df["TRIX"] < 0) & (df["TRIX"].shift(1) >= 0)

    print("\n=== TRIX 上穿零轴 ===")
    print(df[df["zero_cross_up"]][["close", "TRIX"]].to_string())
    print("\n=== TRIX 下穿零轴 ===")
    print(df[df["zero_cross_down"]][["close", "TRIX"]].to_string())

    # 信号线交叉
    df["sig_cross_up"] = (df["TRIX"] > df["Signal"]) & \
                         (df["TRIX"].shift(1) <= df["Signal"].shift(1))
    df["sig_cross_down"] = (df["TRIX"] < df["Signal"]) & \
                           (df["TRIX"].shift(1) >= df["Signal"].shift(1))

    print("\n=== TRIX 上穿信号线 ===")
    print(df[df["sig_cross_up"]][["close", "TRIX", "Signal"]].head(10).to_string())

四、指标能解决的问题

1. 过滤市场噪声

TRIX 的核心价值在于它的三重平滑效果。大量的短期随机波动被层层 EMA 过滤，只有真正有持续性的价格变动才能影响 TRIX 值。

2. 零轴交叉（趋势转变）

信号条件含义
买入TRIX 上穿零轴三重平滑后的价格开始上涨 → 持续性上升趋势开始
卖出TRIX 下穿零轴三重平滑后的价格开始下跌 → 持续性下降趋势开始

3. 信号线交叉

  • TRIX 上穿信号线 → 动量增强，买入信号
  • TRIX 下穿信号线 → 动量减弱，卖出信号

4. 背离信号

由于 TRIX 高度平滑，其背离信号更加可靠：

  • 顶背离：价格新高 + TRIX 未创新高 → 长期动量衰退的可靠信号
  • 底背离：价格新低 + TRIX 未创新低 → 长期动量恢复的可靠信号

5. 趋势强度判断

  • TRIX 绝对值持续增大 → 趋势加速
  • TRIX 绝对值开始减小 → 趋势减速
  • TRIX 接近零轴 → 趋势即将转变
注意

TRIX 的三重平滑使其反应非常缓慢。它适合捕捉大趋势，但会错过短期波动机会。在快速反转的市场中，TRIX 信号可能严重滞后。

五、优缺点与适用场景

优点

优点说明
极强的滤噪能力三重 EMA 几乎完全消除短期噪声
假信号极少高度平滑使得只有真正的趋势变化才产生信号
信号可靠零轴交叉和信号线交叉的准确率较高
背离更可靠平滑后的背离信号比原始价格的背离更有意义

缺点

缺点说明
严重滞后三重平滑导致信号延迟大，可能错过行情初段
不适合短线过度平滑使其无法响应短期价格变化
参数敏感周期选择对信号时机影响较大
趋势行情才有效在长期震荡市场中 TRIX 在零轴附近反复穿越

适用场景

  • 中长线趋势交易：捕捉持续数周至数月的趋势
  • 位置管理：TRIX 方向可作为持仓方向的参考
  • 过滤器：仅在 TRIX > 0 时考虑做多策略
  • 宽基指数：在波动相对平稳的指数上效果较好

与相关指标的对比

比较项TRIXMACDROC
平滑程度极高（3重EMA）中（2重EMA差值）无
滞后性大中小
假信号率极低低高
适合周期长线中线短线

实战建议
  1. 与短期指标互补：TRIX 判断大方向，RSI 或 Stochastic 找具体入场点。
  2. 缩短周期：如果需要更灵敏的信号，可以将周期从 15 降到 8-10。
  3. 关注斜率变化：即使 TRIX 仍为正值，当其斜率从正变负时（从上升变为下降），就是趋势减速的早期预警。
  4. 月线级别：在月线上使用 TRIX(12) 可以捕捉年度级别的大趋势。
