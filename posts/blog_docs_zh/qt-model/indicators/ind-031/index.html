相对强弱指数 (RSI) — 金融量化指标教程

Haiyue
December 20, 2025
6min

一、什么是 RSI 指标

相对强弱指数（Relative Strength Index，简称 RSI）是技术分析中最广泛使用的动量振荡指标之一。它通过比较一段时期内价格上涨与下跌的幅度，衡量价格变动的速度和力度，从而判断资产是否处于超买或超卖状态。

历史背景

RSI 由美国技术分析大师 J. Welles Wilder Jr. 于 1978 年在其经典著作《New Concepts in Technical Trading Systems》中首次提出。Wilder 同时发明了 ATR、ADX、Parabolic SAR 等多个至今仍被广泛使用的指标。RSI 因其简洁的逻辑和强大的实用性，迅速成为所有主流交易平台的标配指标。

指标分类

  • 类型：振荡指标（Oscillator），独立面板显示
  • 大类：动量指标（Momentum）
  • 默认参数：周期 n=14n = 14n=14，数据源为收盘价（Close）
  • 取值范围：0 — 100
常见参数选择
  • 短期：RSI(7) 或 RSI(9) — 信号灵敏，适合短线交易
  • 标准：RSI(14) — Wilder 推荐的默认周期，平衡敏感度与稳定性
  • 长期：RSI(21) 或 RSI(25) — 信号更少但更可靠

二、数学原理与计算方法

核心公式

RSI 的计算分为两步：先计算相对强度（RS），再归一化到 0-100 的范围。

第一步：计算涨跌幅

ΔPt=Pt−Pt−1\Delta P_t = P_t - P_{t-1}ΔPt​=Pt​−Pt−1​

将涨跌幅分离为：

  • 上涨幅度：Ut=max⁡(ΔPt,0)U_t = \max(\Delta P_t, 0)Ut​=max(ΔPt​,0)
  • 下跌幅度：Dt=max⁡(−ΔPt,0)D_t = \max(-\Delta P_t, 0)Dt​=max(−ΔPt​,0)

第二步：使用 Wilder 平滑（SMMA）计算平均涨跌幅

首次计算（第 nnn 期）使用简单平均：

U‾n=1n∑i=1nUi,D‾n=1n∑i=1nDi\overline{U}_n = \frac{1}{n}\sum_{i=1}^{n} U_i, \quad \overline{D}_n = \frac{1}{n}\sum_{i=1}^{n} D_iUn​=n1​∑i=1n​Ui​,Dn​=n1​∑i=1n​Di​

此后使用 Wilder 递推平滑（等价于 α=1/n\alpha = 1/nα=1/n 的 EMA）：

U‾t=(n−1)⋅U‾t−1+Utn,D‾t=(n−1)⋅D‾t−1+Dtn\overline{U}_t = \frac{(n-1) \cdot \overline{U}_{t-1} + U_t}{n}, \quad \overline{D}_t = \frac{(n-1) \cdot \overline{D}_{t-1} + D_t}{n}Ut​=n(n−1)⋅Ut−1​+Ut​​,Dt​=n(n−1)⋅Dt−1​+Dt​​

第三步：计算 RS 与 RSI

RS=U‾tD‾tRS = \frac{\overline{U}_t}{\overline{D}_t}RS=Dt​Ut​​

RSI=100−1001+RSRSI = 100 - \frac{100}{1 + RS}RSI=100−1+RS100​

等价形式：

RSI=100⋅U‾tU‾t+D‾tRSI = \frac{100 \cdot \overline{U}_t}{\overline{U}_t + \overline{D}_t}RSI=Ut​+Dt​100⋅Ut​​

逐步计算逻辑

  1. 计算每日涨跌幅 ΔPt\Delta P_tΔPt​
  2. 分离正负变动：上涨为正值，下跌取绝对值
  3. 初始化：对前 nnn 期的涨跌幅分别求简单平均
  4. 递推平滑：后续每期使用 Wilder 平滑公式更新
  5. RS = 平均上涨 / 平均下跌
  6. RSI = 100 - 100/(1+RS)
为什么使用 Wilder 平滑？

Wilder 平滑（SMMA）赋予历史数据逐渐衰减的权重，使 RSI 值更加稳定，不会因单日极端波动而产生剧烈跳变。这种平滑方式等价于周期为 2n−12n-12n−1 的 EMA。

三、Python 代码实现

import numpy as np
import pandas as pd


def rsi(close: pd.Series, period: int = 14) -> pd.Series:
    """
    计算相对强弱指数 (RSI) — 使用 Wilder 平滑法

    Parameters
    ----------
    close : pd.Series
        收盘价序列
    period : int
        计算周期，默认为 14

    Returns
    -------
    pd.Series
        RSI 值序列（0-100）
    """
    delta = close.diff()

    gain = delta.where(delta > 0, 0.0)
    loss = (-delta).where(delta < 0, 0.0)

    # 第一个平均值使用简单平均
    avg_gain = gain.copy()
    avg_loss = loss.copy()

    avg_gain.iloc[:period] = np.nan
    avg_loss.iloc[:period] = np.nan
    avg_gain.iloc[period] = gain.iloc[1:period + 1].mean()
    avg_loss.iloc[period] = loss.iloc[1:period + 1].mean()

    # Wilder 递推平滑
    for i in range(period + 1, len(close)):
        avg_gain.iloc[i] = (avg_gain.iloc[i - 1] * (period - 1) + gain.iloc[i]) / period
        avg_loss.iloc[i] = (avg_loss.iloc[i - 1] * (period - 1) + loss.iloc[i]) / period

    rs = avg_gain / avg_loss
    rsi_values = 100 - 100 / (1 + rs)

    return rsi_values


# ========== 使用示例 ==========
if __name__ == "__main__":
    np.random.seed(42)
    dates = pd.date_range("2024-01-01", periods=120, freq="D")
    price = 100 + np.cumsum(np.random.randn(120) * 1.5)

    df = pd.DataFrame({
        "date": dates,
        "open":  price + np.random.randn(120) * 0.3,
        "high":  price + np.abs(np.random.randn(120) * 0.8),
        "low":   price - np.abs(np.random.randn(120) * 0.8),
        "close": price,
        "volume": np.random.randint(1000, 10000, size=120),
    })
    df.set_index("date", inplace=True)

    # 计算 RSI
    df["RSI_14"] = rsi(df["close"], period=14)

    # 生成超买/超卖信号
    df["signal"] = np.where(
        df["RSI_14"] > 70, -1,     # 超买 → 卖出信号
        np.where(df["RSI_14"] < 30, 1, 0)  # 超卖 → 买入信号
    )

    print("=== RSI 计算结果（最后 15 行）===")
    print(df[["close", "RSI_14", "signal"]].tail(15).to_string())

    print("\n=== 超买/超卖信号点 ===")
    signals = df[df["signal"] != 0]
    print(signals[["close", "RSI_14", "signal"]].to_string())

四、指标能解决的问题

1. 超买 / 超卖判断

RSI 最经典的用法是识别价格的极端状态：

区域条件含义
超买区RSI > 70短期涨幅过大，可能回调
超卖区RSI < 30短期跌幅过大，可能反弹
中性区30 ≤ RSI ≤ 70无极端信号
注意

在强趋势行情中，RSI 可能长期停留在超买或超卖区域。单纯依据超买/超卖做逆势交易会导致严重亏损。建议结合趋势指标（如 ADX）确认当前是否处于趋势行情。

2. 背离信号（Divergence）

背离是 RSI 最有价值的信号之一：

  • 顶背离（Bearish Divergence）：价格创新高，但 RSI 未创新高 → 上涨动能衰竭，潜在顶部
  • 底背离（Bullish Divergence）：价格创新低，但 RSI 未创新低 → 下跌动能衰竭，潜在底部

3. 中线交叉

  • RSI 上穿 50 → 上涨动能增强，看多
  • RSI 下穿 50 → 下跌动能增强，看空

4. 失败摆动（Failure Swing）

Wilder 认为「失败摆动」是 RSI 最可靠的信号：

  • 顶部失败摆动：RSI 突破 70 后回落，反弹未能再次突破 70，随后跌破前低 → 卖出
  • 底部失败摆动：RSI 跌破 30 后反弹，回落未能再次跌破 30，随后突破前高 → 买入

五、优缺点与适用场景

优点

优点说明
界限清晰0-100 的固定范围，超买/超卖阈值直观
领先性背离信号常领先于价格转折
通用性强适用于股票、期货、外汇、加密货币等所有市场
计算高效递推公式使得实时计算非常快速

缺点

缺点说明
趋势市假信号强趋势中 RSI 可长期处于超买/超卖区，逆势信号失效
参数敏感不同周期 RSI 信号差异大，需针对市场调优
单一维度仅基于价格变动幅度，未考虑成交量等信息
钝化问题极端行情下 RSI 在高位或低位钝化，失去参考价值

适用场景

  • 震荡市场：RSI 在区间震荡行情中表现最佳，超买超卖信号准确率高
  • 背离检测：在趋势末期寻找反转机会
  • 过滤器：结合趋势指标使用，如「仅在 RSI < 40 且价格在 200 日均线之上时做多」

比较项RSIStochasticCCI

灵敏度中等较高较高
适合周期中长期短期中期

实战建议
  1. 多周期确认：同时观察日线 RSI(14) 和周线 RSI(14)，当两者方向一致时信号更可靠。
  2. 动态阈值：在牛市中可将超买阈值调至 80，超卖调至 40；熊市反之。
  3. 结合成交量：RSI 背离 + 成交量萎缩 = 更强的反转信号。
  4. 避免单独使用：RSI 最好作为确认工具，而非唯一的入场信号。
