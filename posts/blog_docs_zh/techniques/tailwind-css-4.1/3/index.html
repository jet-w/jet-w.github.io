第 3 章：样式与美化

学习目标
  • 掌握颜色系统和自定义颜色配置
  • 学会字体、文本和排版相关工具类
  • 熟练使用边框、阴影和背景效果
  • 了解过渡和动画工具类的使用

自定义颜色

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        // 添加自定义颜色
        'brand-blue': '#1e40af',
        'brand-gray': '#6b7280',
        // 添加颜色系列
        'custom': {
          50: '#f8fafc',
          100: '#f1f5f9',
          500: '#64748b',
          900: '#0f172a',
        }
      }
    }
  }
}
<!-- 使用自定义颜色 -->
<div class="bg-brand-blue">品牌蓝色</div>
<div class="bg-custom-500">自定义颜色</div>

文本和排版

字体系列

<!-- 字体系列 -->
<p class="font-sans">Sans-serif 字体</p>
<p class="font-serif">Serif 字体</p>
<p class="font-mono">Monospace 字体</p>

<!-- 自定义字体配置 -->
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      fontFamily: {
        'custom': ['Inter', 'system-ui', 'sans-serif'],
        'chinese': ['PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'sans-serif']
      }
    }
  }
}

文本对齐和处理

<!-- 文本对齐 -->

<p class="text-right">右对齐</p>

<!-- 文本溢出处理 -->

</div>

<div class="w-32">
  <p class="overflow-hidden">

      这是一段很长的文本，会在两行后被截断并显示省略号
    </span>
  </p>
</div>

<!-- 空白字符处理 -->

<p class="whitespace-normal">正常换行</p>
<p class="whitespace-pre">保持空白格式</p>

  </p>
</div>

动画最佳实践
  1. 性能考量：优先使用 CSS 变换而非改变布局属性
  2. 用户体验：动画应该增强而非干扰用户体验
  3. 可访问性：尊重用户的动画偏好设置
  4. 适度使用：避免过度使用动画导致页面混乱

小结

通过本章学习，你应该掌握了：

  • 颜色系统：Tailwind 的完整颜色调色板和透明度控制
  • 排版工具：字体、大小、粗细、对齐等文本控制
  • 边框和阴影：创建视觉层次和深度效果
  • 背景效果：纯色、渐变和图片背景的应用
  • 动画过渡：为用户交互添加流畅的视觉反馈

这些样式工具类让你能够创建美观、现代化的用户界面。下一章我们将学习 Tailwind CSS 的进阶特性，包括自定义指令和组件抽取。
