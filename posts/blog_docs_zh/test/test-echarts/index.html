ECharts 图表组件测试

本文演示如何在 MDX 文件中使用 ECharts 组件来展示数据可视化图表。

折线图示例

饼图示例

柱状图示例

使用说明

组件属性

属性类型默认值说明
optionObject必填ECharts 配置项
widthString’100%‘图表宽度
heightString’400px’图表高度
themeString’light’主题：‘light’ 或 ‘dark’
autoResizeBooleantrue是否自动调整大小

基本用法

import EChartsTest from '../../components/ECharts_Test.vue'

<ECharts
  client:only="vue"
  option={{
    xAxis: { type: 'category', data: ['A', 'B', 'C'] },
    yAxis: { type: 'value' },
    series: [{ type: 'bar', data: [10, 20, 30] }]
  }}
/>

注意：必须添加 client:only="vue" 指令才能在客户端渲染图表。
